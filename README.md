# Project Board

PWA-дашборд для управления проектами: платформа виджетов (вкладки, каталог, тайлинг/каскад) и модули чек-листа и Гантта.

**Текущая стадия:** платформа дашборда завершена: вкладки, каталог виджетов, рамка окон (сворачивание/закрытие/активность), тайлинг и каскад с переключением режимов на вкладке, восстановление всего пространства после перезапуска, каталог документов с переименованием, удалением и повторным открытием (dropdown-панели), версии БД и миграции документов с защитой от перезаписи документов будущих версий, жизненный цикл скрытых виджетов (вкладки не размонтируются, видимость и размеры передаются виджетам, ошибки рендера изолированы); чек-лист с общими документами; локальное хранение и автосохранение (IndexedDB). **Ядро Гантта завершено:** документ плана v1, операции над задачами и ручными датами, иерархия групп со сводными сроками, справочники ресурсов и типов работ с параллельностью, назначения задач и периоды недоступности, FS-зависимости с защитой графа, диагностика конфликтов ресурсов и отпусков ([ADR PBT-017](.docs/adr/PBT-017.md): SVAR — проектный вид, React Calendar Timeline — ресурсный).  **Редизайн по прототипу (PBT-069–075):** тёмная тема на токенах, рамка окон, разворачивание на весь дашборд, каркас дашборда (топ-бар, вкладки, каталоги), проектный Гантт: тёмная тема SVAR с локальными wx-icons (офлайн), тулбар в две строки, зум Дни/Недели, таблица 5 колонок, сохранение прокрутки шкалы при развороте (техдолг PBT-071 закрыт); ресурсный вид: тёмная тема RCT, аватары-инициалы в сайдбаре, легенда с диапазоном видимой области, дневной снап полос, точный слой нерабочих дней; чек-лист: прогресс-бар, persisted-скрытие выполненных, оформление и иконки по прототипу. **Представления:** проектный Гантт из документа плана: просмотр (дерево, сводные, включительные даты, рабочая длительность, подсветка нерабочих дней), форма создания/редактирования/удаления задач с доменной валидацией и перетаскивание полос с изменением длины — правила ручного расписания PBT-003 (перенос сохраняет рабочую длительность, брошенный край сохраняется как введён) применяются командами ядра; запись документа — одна операция на жест. Серия редактирования и представлений PBT-038–049 смержена ([PR#38](https://github.com/RenatKunafin/project-board/pull/38)): управление группами, справочники и ресурсы в интерфейсе, FS-зависимости и конфликты в UI, список проблем с переходом к задаче, ресурсные дорожки (RCT) с нерабочими днями, редактированием сроков и формой задач, фильтры (текст/ресурс) и сохраняемые состояния представлений (масштаб, раскрытие групп). **Обмен файлами начат:** собственный формат плана (PBT-050, [PR#39](https://github.com/RenatKunafin/project-board/pull/39)) — версионированный JSON с конвертом (`format`/`formatVersion`), полной диагностикой при импорте, политикой независимого плана и round-trip без потерь; UI импорта/экспорта плана (PBT-051, [PR#40](https://github.com/RenatKunafin/project-board/pull/40)) — скачивание `pb-plan-…json` и открытие файла через браузерный диалог с валидацией до сохранения; парсер OnlineGantt `.gantt` (PBT-052, [PR#41](https://github.com/RenatKunafin/project-board/pull/41)) — разбор рабочего формата в план с отчётом импорта: иерархия `subtasks` → группы, даты по таймзоне файла, FS-лаги, сохранение `unit`/примечаний; UI импорта `.gantt` (PBT-053, [PR#42](https://github.com/RenatKunafin/project-board/pull/42)) — предпросмотр со сводкой и предупреждениями до создания, применение создаёт независимый план и открывает его в окне; преобразование задач в отпуска (PBT-054, [PR#44](https://github.com/RenatKunafin/project-board/pull/44)) — диалог с явным выбором ресурса и атомарной заменой задачи периодом недоступности; генератор PlantUML (PBT-055, [PR#45](https://github.com/RenatKunafin/project-board/pull/45)) — публикация плана диаграммой в стиле целевого примера (палитра этапов, отпуска, серые выходные, русская шкала) с отчётом о непереносимом; экспорт PlantUML из интерфейса (PBT-056, [PR#46](https://github.com/RenatKunafin/project-board/pull/46)) — предпросмотр текста с ограничениями, копирование и скачивание `.puml`. Обмен файлами завершён: собственный формат, импорт OnlineGantt `.gantt` с преобразованием отпусков, публикация PlantUML. **Редизайн:** дизайн-токены и тёмная тема по прототипу `flexi-dashboard-hub` (PBT-069, [PR#47](https://github.com/RenatKunafin/project-board/pull/47)) — oklch-палитра поверхностей, локальные шрифты IBM Plex Sans/JetBrains Mono, единый файл токенов; рамка окна в стиле прототипа (PBT-070, [PR#48](https://github.com/RenatKunafin/project-board/pull/48)); разворачивание окна на весь дашборд (PBT-071, [PR#49](https://github.com/RenatKunafin/project-board/pull/49)); каркас дашборда (PBT-072, [PR#50](https://github.com/RenatKunafin/project-board/pull/50)) — топ-бар со сводным индикатором сохранения всех документов, вкладки с акцентом, сегмент «Сетка/Каскад», карточки каталогов с описаниями типов и счётчиком открытых окон, пустое состояние с действием; доводка Гантта (PBT-076, [PR#55](https://github.com/RenatKunafin/project-board/pull/55)) — недельная семантика зума («Недели» = колонка-неделя 16px/день с подписями «12.10–18.10», неделя с понедельника, дневная точность полос и подсветки), строка фильтров тулбара по прототипу, клампинг каскадных окон в границы канваса. Дальше — по решению владельца: PWA (PBT-028/029) или подготовка первой версии (PBT-057+). Прогресс и статусы — [реестр задач](.context/tasks/README.md).

## Запуск

Требуется Node.js ≥ 22 (в разработке используется v22.12.0, npm 11.2.0).

```bash
npm install        # установка зависимостей по lockfile (или npm ci)
npm run dev        # основное приложение: http://localhost:5173
npm run dev:load-demo  # нагрузочный стенд Гантта: http://localhost:5176 (не в прод-сборке, до PBT-058)
npm run build      # production-сборка в apps/project-board/dist
npm run preview    # отдача собранной страницы: http://localhost:4173
npm run typecheck  # tsc --noEmit по всем пакетам
npm run lint       # ESLint: код + границы импортов (ADR PBT-002)
npm test           # unit-тесты (Vitest)
npm run test:browser  # UI-проверки (Playwright; локально: npx playwright install chromium)
```

CI (GitHub Actions) на каждый PR в `develop`: lint → typecheck → unit → build → `openspec validate --all --strict`.

## Структура

```text
apps/project-board      # Сборка PWA: Vite + React + TS, оболочка приложения
apps/load-demo          # Нагрузочный стенд Гантта (PBT-016), не входит в прод-сборку
packages/dashboard      # Универсальная платформа дашборда
packages/widget-sdk     # Публичный контракт платформы и модулей
packages/gantt          # Модуль Гантта (зависит от widget-sdk)
packages/checklist      # Модуль чек-листа (зависит от widget-sdk)
```

Направления зависимостей — [ADR PBT-002](.docs/adr/PBT-002.md): модули используют `widget-sdk`; платформа не импортирует предметные модули; точка регистрации типов виджетов — `apps/project-board/src/widgets.ts`.
