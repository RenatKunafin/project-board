# PBT-021 — Тайлинг по сетке

## Why

После PBT-020 окна имеют рамку, но раскладка — фиксированная двухколоночная сетка приложения без переноса и изменения размеров. Согласованное поведение (решения §4.2): виджеты привязываются к сетке дашборда, переносятся за заголовок, меняют размер, соседи сдвигаются без итогового перекрытия, пустые места допустимы, нехватка высоты даёт вертикальную прокрутку. Это первый из двух режимов размещения (каскад — PBT-022), и его раскладка должна сериализоваться для восстановления рабочего пространства (PBT-024).

## What Changes

- В `packages/dashboard` появляется адаптер сеточной раскладки `TiledLayout`: кандидат React Grid Layout (MIT, решения §19) изолируется внутри адаптера — приложение и виджеты не знают о библиотеке.
- Перенос за заголовок окна (ручка — заголовок из PBT-020) с предпросмотром позиции (placeholder); редактирование внутри виджета перенос не запускает.
- Изменение размера за уголок с соблюдением минимальных (и максимальных, если заданы) размеров из `sizeConstraints` зарегистрированного типа.
- Соседи сдвигаются без итогового перекрытия; пустые места допустимы; нехватка высоты — вертикальная прокрутка пространства вкладки.
- Сворачивание согласовано с сеткой: свёрнутое окно занимает одну строку (заголовок), разворачивание возвращает прежнюю высоту (ADR-7 PBT-002).
- Раскладка хранится и сериализуется в собственной структуре платформы (`instanceId → {x, y, w, h}`) без привязки документов и экземпляров к библиотечным объектам; состояние в памяти, персистентность — PBT-024.
- Ограничение: один режим на вкладку на данном этапе — переключение тайлинг/каскад приходит в PBT-023, раскладка каскада не затрагивается.
- Delta spec: новая capability `widget-layouts`.

## Capabilities

### New Capabilities

- `widget-layouts` — сеточное размещение: привязка к сетке и сдвиг соседей, перенос за заголовок с предпросмотром, изменение размеров по ограничениям типа, согласование сворачивания с сеткой, сериализуемая раскладка.

### Modified Capabilities

- Нет.

## Non-goals

- Каскад и переключение режимов размещения (PBT-022–023): раскладки режимов и их раздельное хранение не реализуются.
- Персистентность раскладки и восстановление после перезапуска (PBT-024).
- Пауза отрисовки при переносе/скрытии (PBT-027).
- Стилистика под макеты (PBT-066): сетка стилизуется на текущих токенах.
- Мобильные раскладки (ADR PBT-002: десктоп).

## Impact

- Новые файлы: `packages/dashboard/src/tiled-layout.ts` (сериализация/ограничения) и `packages/dashboard/src/TiledLayout.tsx` (адаптер) + тесты; delta spec `specs/widget-layouts/spec.md`.
- Изменённые: `packages/dashboard/src/index.ts`, `packages/dashboard/package.json` (react-grid-layout + типы), `apps/project-board/src/App.tsx` (панели вкладки рендерятся через адаптер), `apps/project-board/src/index.css` (стили сетки, импорт базовых стилей RGL), e2e.
- Разблокирует: PBT-022 (каскад и режимы), PBT-024 (восстановление раскладки).
