## Порядок завершения после одобрения PR

После одобрения PR владельцем синхронизировать notes spec и архивировать change заключительным коммитом, дождаться CI этого коммита и выполнить merge. По подтверждённому merge обновить локальный реестр; до merge задача не получает статус Done.
