## Why

PBT-120/121 подтвердили работу внутреннего агента через MCP stdio и полный обмен с локальной страницей на рабочем Mac. Стенд не определяет надёжную очередь, восстановление полномочий и доказательство сохранения при конкуренции; без единого контракта PBT-123–132 могут реализовать несовместимые решения.

## What Changes

- Подготовить документационный контракт первой версии: режим без аналитики, один источник/доска и обновление отдельного документа спринта по явному запросу. Размещение страницы уточняется с владельцем.
- Зафиксировать доказанные результаты и ограничения исследований, включая отказ публичного HTTPS → HTTP-loopback на рабочем Mac, оставленные клиентом процессы и наблюдавшиеся ошибки 429. Дословное свидетельство владельца от 07.11 указывает на отказ доступа к loopback; прежняя интерпретация как корпоративного HTTPS-апгрейда исправлена в отчёте PBT-121. Причину отказа LNA и доступность публичного варианта на рабочем Mac ещё нужно установить.
- Описать идентичность, версии, сопряжение и отзыв доступа; конверты запросов/результатов/ошибок; состояния, дедупликацию, сроки, восстановление очереди и подтверждение записи документа.
- Распределить проверки между компонентом, платформой и предметным модулем; разобрать сбои, несколько окон, backup/restore и смену конфигурации.
- После ревью оформить постоянный контракт в `docs/agent-integration.md`, уточнить связанные карточки и дорожную карту. Проект контракта подготовлен в `design.md`: один HTTP JSON API допускает публичный HTTPS-origin и локальный origin. Место размещения определяется проверкой среды до пилота; обязательного перехода на локальную сборку нет.

Вне объёма: реализация компонентов PBT-123–136, новый универсальный CRUD/чтение всех документов, изменение Jira или ручного плана, расписание агента, burndown, публикация пакета/Release, корпоративное развёртывание.

## Capabilities

### New Capabilities

Нет: PBT-122 меняет только документацию, `skip_specs: true`. Будущие `agent-connection`, `agent-requests`, `sprint-data` описываются delta specs в реализующих их задачах.

### Modified Capabilities

Нет: действующее поведение приложения и основные specs не меняются.

## Impact

- В текущем change: proposal/design/tasks и исправление неподтверждённого вывода отчёта PBT-121; после согласования — постоянная документация, её навигация и локальный план серии.
- Будущие изменения: PBT-123 — отдельный профиль сборки и кешей; PBT-124/125 — локальный процесс и очередь; PBT-126 — платформенный путь атомарного сохранения с квитанцией и восстановление ACK; PBT-127/128 — модель и виджет спринта; PBT-129 — ограниченная обработка агентом.
- Публичный `DocumentService.update()` остаётся синхронным. Новая внутренняя операция платформы и миграция её хранилища только проектируются; platform/SDK не импортируют предметные пакеты.
- Зависимости не добавляются и не обновляются. Проверенная в стенде версия MCP SDK — исторический факт, а не утверждение о текущей latest.
