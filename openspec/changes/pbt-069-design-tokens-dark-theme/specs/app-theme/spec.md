## ADDED Requirements

### Requirement: Тёмная тема приложения

Приложение SHALL отображать рабочее пространство в тёмной теме с различимыми уровнями поверхностей: панели каркаса темнее фона канваса, фон канваса темнее поверхностей окон, заголовки окон и шапки таблиц выделяются приподнятой поверхностью.

#### Scenario: Поверхности различимы

- **GIVEN** открытое приложение и вкладка хотя бы с одним окном виджета
- **WHEN** отображается рабочее пространство
- **THEN** панель вкладок, фон канваса и поверхность окна имеют различные тёмные оттенки
- **AND** активное окно выделяется рамкой акцентного цвета и тенью

### Requirement: Локальные шрифты

Приложение SHALL загружать шрифты интерфейса (основной и моноширинный) из собственной сборки без внешних сетевых запросов.

#### Scenario: Нет внешних запросов шрифтов

- **GIVEN** загруженное приложение
- **WHEN** проверяются сетевые запросы страницы
- **THEN** запросы шрифтов адресованы только собственной сборке
- **AND** основной текст отображается шрифтом IBM Plex Sans, моноширинные фрагменты — JetBrains Mono

### Requirement: Токены — единственный источник цветов

Все цвета интерфейса SHALL определяться CSS-переменными из единого файла токенов; литеральные цветовые значения вне этого файла запрещены.

#### Scenario: Проверка источника цветов

- **GIVEN** исходные файлы стилей приложения и пакетов
- **WHEN** выполняется поиск литеральных цветовых значений
- **THEN** совпадения найдены только в файле токенов
