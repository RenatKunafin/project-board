# PBT-078 — Привязка каскадных окон к сетке

## Why

Владелец требует дискретный перенос и ресайз окон каскада. Сейчас фон имеет шаг 16px, но react-rnd перемещает окна свободно. По уточнению владельца референс привязки — режим сетки прототипа: округление абсолютных координат/размеров до ближайшего узла, шаг по умолчанию 16px, дискретное отображение во время жеста и фиксация после отпускания. Это поведение применяется к нашему каскаду независимо от несовершенств каскадного режима самого прототипа.

## What Changes

- По ревью владельца: расширяемый логический канвас с прокруткой по обеим осям вместо ограничения видимым экраном; новые окна занимают свободное место и становятся доступны через прокрутку.
- Постоянная привязка перемещения и изменения размеров каскадных окон к сетке 16×16px.
- Согласованность отображаемой сетки, интерактивного жеста и сохранённой итоговой геометрии.
- Сохранение ограничений размера типа, достижимости окна и границ канваса, сворачивания и разворачивания.
- Нормализация старых каскадных координат на отображение без миграции БД, сохранение нормализованной геометрии при завершённом жесте.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `widget-layouts`: дискретные жесты каскада и восстановление геометрии с учётом сетки.

## Impact

Адаптер react-rnd и чистые функции каскадной геометрии в dashboard, CSS точечной сетки, проверки геометрии и браузерные сценарии. SDK и схемы данных не меняются.

## Non-Goals

Пользовательская настройка шага/отключение привязки, изменение тайлинга, сдвиг соседних окон каскада, изменение внутреннего drag/resize Гантта, иконки (PBT-077).
