## Why

Запрос владельца: дать задаче цвет, выбираемый пользователем, и показать его в Гантте и ресурсном плане (карточка PBT-084; референс — раздел 6 «P2 — цвет задачи как данные плана» обновлённого прототипа `MVP-DESIGN-TASKS.md` и его реализация `src/lib/task-colors.ts`, `TaskColorPicker.tsx`). Выбор встроен в общую форму задачи PBT-087; поручение 2026-10-26: палитра совместима с экспортом PlantUML.

## What Changes

- Поле `color` у задачи плана: опциональный **идентификатор из конечной палитры** (не hex и не CSS-строка); отсутствие значения — «Авто»; неизвестный идентификатор отклоняется валидацией при чтении. Схема документа и формат файла остаются v1.
- Палитра — десять значений референса (сапфир, бирюза, нефрит, лайм, охра, тыква, коралл, роза, слива, сталь) плюс «Авто» (accent темы); состав и порядок — как в `src/lib/task-colors.ts`.
- Отображение в обоих видах генерируемыми CSS-правилами по идентификатору задачи: SVAR — подмешивание в переменные темы (`--wx-gantt-task-color` через `color-mix` с `--surface`, `--wx-gantt-task-fill-color`, `--wx-gantt-task-border-color`); ресурсный план — `--resource-color`. Правило выдаётся только для идентификатора, безопасного для селектора (`/^[A-Za-z0-9_-]+$/`), остальные задачи — «Авто».
- Форма задачи: fieldset «Цвет» — «Авто» и десять кружков (`aria-pressed`, отметка выбранных); тот же набор кружков в портальном меню быстрой смены.
- Быстрая смена: контекстное меню на полосе задачи (правый клик) в обоих видах — вне окна, поверх слоёв, закрытие Escape и кликом вне, координаты ограничены viewport; применяет ту же команду изменения цвета документа.
- Конфликт и отпуск остаются собственными маркерами: проблемная полоса сохраняет цвет конфликта, не выбранный цвет; «Авто» возвращает accent темы.
- Экспорт/импорт собственного формата сохраняют выбор (round-trip идентификатора); PlantUML: задача с цветом экспортируется hex-значением палитры (`is colored in #rrggbb/#rrggbb`), приоритетно над палитрой этапов.
- OnlineGantt `.gantt`: цвет записи переносится только при точном совпадении hex (нормализация регистра) со значением палитры; без совпадения — «Авто»; собственный формат: неизвестный идентификатор цвета нормализуется в «Авто» на шаге разбора, без смягчения остальных проверок (решение владельца 2026-10-26: нормализация вместо отклонения при импорте).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `planning-documents`: поле `color` — идентификатор палитры, валидация известности, сохранение командами.
- `project-gantt`: окраска полосы, поле цвета в форме, быстрая смена правым кликом.
- `resource-timeline`: окраска элемента дорожки, быстрая смена, приоритет конфликта.
- `plan-transfer`: round-trip цвета; политика цвета OnlineGantt (перенос только при совпадении с палитрой).
- `plantuml-export`: ручной цвет (hex палитры) приоритетнее палитры этапов.

## Impact

Модель и валидация `packages/gantt/plan-document.ts`, команды задач, черновик/форма задачи, новый модуль палитры (`task-colors`-эквивалент), адаптеры SVAR и ресурсного вида, портальное меню быстрой смены, генератор PlantUML, парсер OnlineGantt, CSS виджетов. Схема v1 и формат v1 не меняются; миграция не нужна. Семантика планирования (ADR PBT-003), жесты (ADR PBT-017), бюджеты не затрагиваются.

## Non-Goals

Произвольный ввод hex в UI и хранение hex в документе, цвет групп/сводных полос, окраска по типу работы, подмена цветом подсветки конфликтов и отпусков, изменение легенды этапов в файле PlantUML, экспорт в OnlineGantt, смена версии схемы/формата.
