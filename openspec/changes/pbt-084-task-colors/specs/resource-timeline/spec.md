## ADDED Requirements

### Requirement: Ручной цвет задачи на дорожках

Ресурсный вид SHALL окрашивать элемент дорожки ручным цветом задачи, если он задан, правилами, адаптированными к теме. Подсветка конфликта сохраняет собственное оформление и приоритет над ручным цветом; отпуска и нерабочие дни отображаются прежним оформлением.

#### Scenario: Назначение окрашено цветом задачи

- **GIVEN** задача с ручным цветом и назначением на ресурса
- **WHEN** план открывается в ресурсном виде
- **THEN** элемент дорожки этой задачи окрашен ручным цветом, элементы задач без цвета — стандартно

#### Scenario: Конфликт перекрывает ручной цвет

- **GIVEN** две задачи одного ресурса с ручными цветами, конфликтующие по параллельности типа работ
- **WHEN** план открывается в ресурсном виде
- **THEN** конфликтные элементы отображаются подсветкой конфликта, а не ручным цветом
