# widget-windows (delta) — PBT-049 Gantt view state

## ADDED Requirements

### Requirement: Состояние представления экземпляра

Платформа SHALL предоставлять виджетам чтение и запись состояния представления экземпляра (ADR-6.4): записанное состояние SHALL сохраняться локально и SHALL доставляться виджету при монтировании панели после перезапуска приложения. Открытие дополнительного представления документа через каталог SHALL выбирать указанный тип виджета и MUST NOT дублировать документ.

#### Scenario: Состояние переживает перезапуск

- **GIVEN** пользователь настроил фильтры и масштаб экземпляра
- **WHEN** приложение перезапускается
- **THEN** экземпляр монтируется с сохранёнными фильтрами и масштабом

#### Scenario: Дополнительное представление без дублирования

- **GIVEN** сохранённый план открыт в проектном виде
- **WHEN** пользователь открывает его же в ресурсном виде через каталог
- **THEN** оба окна ссылаются на один документ
