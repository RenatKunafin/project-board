# PBT-138 — Потеря данных при аварийном завершении браузера (фаза 1)

## Why

Владелец теряет данные при экстренном завершении браузера (kill процесса): дашборд оказывается пустым, восстановление — вручную из бэкапа. До диагностики неизвестен механизм: повреждение/удаление IndexedDB браузером, потеря последних коммитов или дефект приложения. Без точного диагноза митигация была бы стрельбой наугад.

## What Changes

- Исследование без изменения продуктового кода (`skip_specs: true`).
- Стенды воспроизведения `tests/persistence-crash/`: серии kill-тестов (покой / активная запись / граница debounce / тяжёлая БД) на чистом профиле Chrome с production-сборкой; контрольные эксперименты (graceful close против kill); пошаговая локализация с прямыми снимками IndexedDB из страницы.
- Установлен механизм: debounce-сохранение снапшота workspace (`App.tsx`, PBT-024) с эффектом без зависимостей бесконечно откладывается при непрерывной активности; аварийное завершение без `pagehide` теряет окна/вкладки. Документы и LevelDB-каталог сохраняются; corruption-гипотеза опровергнута.
- Отчёт `docs/research/PBT-138.md` с доказательствами и рекомендацией митигации (maxWait, флаш по hidden, немедленная запись структурных операций) для фазы 2.
