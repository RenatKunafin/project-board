## Context

SVAR 2.8.0 меняет `gridWidth` и `displayMode` при действиях штатного разделителя. В проекте `gridWidth=712` задан постоянно; SVAR пересоздаётся при внешних редакциях и смене масштаба. Общий документ и настройки экземпляра уже разделены.

## Goals / Non-Goals

Сохранять выбор пользователя при существующем жизненном цикле диаграммы. Не менять стратегию пересоздания SVAR, колонок или жестов задач.

## Decisions

- Использовать настройки экземпляра `ganttGridWidth` и `ganttDisplayMode` (`all`/`grid`/`chart`), локальный React-state и актуальный ref для обработчиков.
- Слушать завершение `resize-grid` (пропускать `inProgress`) и `set-display-mode`; читать применённый стор после события. Автоматический resize контейнера не является пользовательским изменением настройки.
- Передавать сохранённые значения при каждом создании Gantt. Неподходящие старые значения настроек заменять действующими defaults 712/all.
- Сравнивать с последним сохранённым значением для исключения лишних обновлений. Следовать имеющейся защите init от повторной регистрации StrictMode.
- Проверять физическое перемещение разделителя и штатные кнопки, а также независимость двух окон одного плана и неизменность его ревизии.

## Risks / Trade-offs

- Полное скрытие панели сохраняется режимом, а не нулём ширины: SVAR запоминает предыдущую ширину для восстановления.
- Промежуточные события drag могут вызвать лишние пересборки → запись только после окончания жеста.
- Старый API после пересоздания не должен перезаписать настройки → проверка актуальности API перед отложенной обработкой.

## Migration Plan

Миграции документа нет. При отсутствии новых настроек используется прежняя раскладка.
