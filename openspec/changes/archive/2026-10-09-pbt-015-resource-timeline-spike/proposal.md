# PBT-015 — Проверить компонент ресурсных дорожек (спайк React Calendar Timeline)

## Why

До решения PBT-017 нужно проверить второй кандидат — React Calendar Timeline — на согласованных правилах ресурсного представления (ADR PBT-003: D1–D7, 13.2 решений): компактные дорожки ресурсов, укладка пересечений, отпуск как недоступность у конкретного ресурса, точность до дня. Проектный Гантт проверен спайком PBT-014 («подходит с ограничениями»); после этого исследования у владельца будут факты по обоим кандидатам.

## What Changes

- Добавляется изолированное экспериментальное приложение `apps/resource-timeline-spike` (Vite, порт 5175), не входящее в прод-сборку; корневой скрипт `dev:resource-spike`.
- Библиотека: `react-calendar-timeline@0.30.0-beta.19` (MIT; TS/React 18–19 ветка, обновлена 2026-07-24; peer: react ^18/19, dayjs, interactjs) — фиксируется точная версия.
- В спайке — адаптер контрольных данных PBT-012 (`small-plan.json`): ресурсы → дорожки (groups), назначенные задачи → элементы (D1: несколько назначений — элемент на дорожке каждого ресурса; D2: неназначенные — не отображаются), отпуск R1 (26–27.10) — элемент недоступности в дорожке R1, выходные по календарю — фон всей шкалы.
- Проверяются пункты DoD: укладка пересекающихся задач внутри дорожки; отпуск виден у ресурса, общий нерабочий день — на всей шкале; drag/resize возвращает календарные даты по нашей семантике (включительное окончание); resize контейнера; React-совместимость и версия зависимости.
- Итог — отчёт `.docs/research/PBT-015.md`: версии, окружение, команды, наблюдения, ограничения, лицензия, вывод «подходит / подходит с ограничениями / не подходит».
- Продуктовый код (`apps/project-board`, `packages/*`) и `apps/gantt-spike` не изменяются; delta specs отсутствуют (`skip_specs: true`).

## Capabilities

### New Capabilities

- Нет: research-задача без изменения продуктового поведения.

### Modified Capabilities

- Нет.

## Non-goals

- Выбор компонента и продуктовая интеграция — PBT-017 и последующие задачи; спайк не становится production-кодом.
- Проектное представление — проверено PBT-014 (`apps/gantt-spike`), здесь не повторяется.
- Ресурсная нагрузка в процентах, календарный учёт частичной занятости — вне первой версии (D3).
- Конфликты ресурсов (подсветка) — ядро PBT-036; спайк только показывает данные.
- Продуктовый импорт `.gantt` — PBT-052+; фикстурные данные берутся напрямую.

## Impact

- Новые файлы: `apps/resource-timeline-spike/**` (временное приложение; судьба после PBT-017 — удалить вместе с `apps/gantt-spike` или принять отдельным решением), `.docs/research/PBT-015.md`.
- Новая зависимость: `react-calendar-timeline@0.30.0-beta.19` + `dayjs`/`interactjs` — только в `apps/resource-timeline-spike`.
- Корневые скрипты: `dev:resource-spike`; `typecheck` корня дополняется проектом спайка.
