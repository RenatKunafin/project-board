## MODIFIED Requirements

### Requirement: Генерация текста PlantUML из плана

Модуль SHALL генерировать из документа плана текст диаграммы PlantUML Gantt, включающий: русскую локаль шкалы, заголовок плана, дату старта проекта (минимальная дата начала задач), закрытые дни недели, праздники и рабочие исключения календаря, группы в виде разделителей, задачи с человекочитаемым названием, уникальным алиасом, явной датой начала и длительностью в рабочих днях, периоды недоступности отдельным разделом отпусков, FS-зависимости стрелками по алиасам, заливку выходных дней по горизонту плана. Задача с ручным цветом SHALL окрашиваться hex-значением палитры цветов проекта для её идентификатора (`is colored in #rrggbb/#rrggbb`); задачи без ручного цвета SHALL публиковаться без явного цвета; отпуска SHALL окрашиваться цветом отпуска. Эвристика этапов по маркерам названия удалена. Генерация SHALL быть чистой функцией: без сети, без изменения документа, детерминированной для одного плана.

#### Scenario: Контрольный план переносится целиком

- **GIVEN** план с календарём (праздник, рабочее исключение, пн–пт), вложенными группами, задачами с исполнителями и FS-зависимостью, периодом недоступности
- **WHEN** выполняется генерация
- **THEN** текст содержит все перечисленные элементы и рендерится в валидную диаграмму закреплённой версии PlantUML
- **AND** отображаемые даты задач совпадают с планом: старт — исходный, длительность — в рабочих днях календаря плана

#### Scenario: Отпуск отображается тёмно-зелёной задачей в разделе отпусков

- **GIVEN** план с периодом недоступности ресурса
- **WHEN** выполняется генерация
- **THEN** текст содержит отдельный раздел отпусков с задачей периода, окрашенной в цвет отпуска палитры

#### Scenario: Ручной цвет приоритетнее этапа

- **GIVEN** задача с ручным цветом `sapphire` и маркером этапа в названии
- **WHEN** выполняется генерация
- **THEN** задача окрашена `#3186e9/#3186e9`, цвет этапа для неё не применяется

#### Scenario: Этап задачи окрашивается по маркеру названия

- **GIVEN** задачи без ручного цвета с маркерами этапов в названиях (например «-ПСИ-», «-DEV-»)
- **WHEN** выполняется генерация
- **THEN** ни одна из них не имеет строки окраски — цвет определяет целевой рендер; файл не содержит легенды этапов

#### Scenario: Задача без рабочих дней выводится вехой

- **GIVEN** задача, чей интервал не содержит рабочих дней календаря плана
- **WHEN** выполняется генерация и рендер
- **THEN** задача отображается вехой-точкой на дате начала вместо полосы

#### Scenario: Рабочее исключение открыто на шкале

- **GIVEN** календарь с рабочим исключением (рабочая суббота)
- **WHEN** диаграмма рендерится
- **THEN** день исключения отмечен открытым и входит в длительность задач через него
