# PBT-041 — Редакторы ресурсов и типов работ

## Why

Справочники плана (ресурсы, типы работ) реализованы в ядре (PBT-033), но не имеют UI: создать QA/QA2 или тип «ПСИ» из приложения нельзя — только dev-хуком. Назначения (PBT-042) и отпуска (PBT-043) требуют существующих записей справочников, поэтому редакторы — следующий шаг серии.

## What Changes

- Диалог «Справочники плана» в виджете проектного Гантта (кнопка тулбара): две секции — «Исполнители» и «Типы работ».
- Ресурсы: добавление (поле + кнопка), инлайн-переименование (Enter/Esc), удаление с подтверждением, поясняющим чистку ссылок (назначения снимаются, периоды недоступности удаляются — контракт ядра, вариант A PBT-033).
- Типы работ: добавление с выбором параллельности, переключение признака флажком прямо в списке, инлайн-переименование, удаление с подтверждением. В шапке секции — пояснение правила с примерами «Разработка — нельзя параллельно, ПСИ — можно».
- Все операции — команды ядра (`createResource`/`updateResource`/`deleteResource`/`createWorkType`/`updateWorkType`/`deleteWorkType`) через существующий `commitPlan` с ретраем; ошибки домена (`invalid-title`, `unknown-*`) показываются у соответствующего поля/строки.
- UI не предлагает модель процентной ёмкости пула (DoD-5) — в интерфейсе нет полей процента/ёмкости.

## Impact

- Новый файл: `packages/gantt/src/ResourceCatalogDialog.tsx` (стили — переиспользование классов `task-editor__*`, прецедент GroupEditorDialog); e2e `tests/e2e/resource-catalogs.spec.ts`.
- Изменённые: `packages/gantt/src/PlanGanttWidget.tsx` (кнопка тулбара «Справочники», состояние диалога), `packages/gantt/src/index.ts` при необходимости.
- Ядро не расширяется; delta spec — `resource-planning`.
- Разблокирует: PBT-042 (назначения), PBT-043 (отпуска) — им нужны существующие записи справочников.

## Non-Goals

- Назначения ресурсов/типов на задачи (PBT-042), периоды недоступности (PBT-043), календари (PBT-044).
- Процентная ёмкость пула (`QA = 300%`) — отклонена в решениях (§11.1), UI не предлагается.
- Drag-сортировка записей справочников; порядок — добавление в конец.
