## MODIFIED Requirements

### Requirement: Восстановление вкладок при старте

При запуске приложения платформа SHALL восстанавливать вкладки из локального хранилища: порядок, названия, активную вкладку и режим размещения каждой вкладки. Если сохранённых вкладок нет, приложение SHALL начать с одной пустой вкладки «Дашборд» без экземпляров виджетов. Пустая вкладка SHALL показывать существующее пустое состояние с действием добавления виджета. Восстановление MUST NOT пересоздавать документы или дополнять пространство демонстрационными окнами. Сохранённая пустая вкладка SHALL восстанавливаться пустой.

#### Scenario: Перезапуск восстанавливает вкладки

- **GIVEN** приложение с вкладками «Чек-листы» (активная) и «План ОКАД» (каскад) закрыто и открыто заново
- **WHEN** рабочее пространство восстанавливается
- **THEN** вкладки в прежнем порядке с прежними названиями, активна «Чек-листы», «План ОКАД» — в режиме каскада

#### Scenario: Первый запуск начинает с исходного состояния

- **GIVEN** локальное хранилище не содержит сохранённых вкладок
- **WHEN** приложение запускается впервые
- **THEN** открывается одна пустая вкладка «Дашборд» без окон виджетов
- **AND** пользователь может создавать вкладки и открывать каталог виджетов из пустого состояния

#### Scenario: Перезапуск пустого пространства

- **GIVEN** пользователь не добавлял виджеты и пустая вкладка сохранена
- **WHEN** приложение перезагружено или повторно открыто
- **THEN** вкладка остаётся пустой, демонстрационные окна не появляются

#### Scenario: Повторный запуск пустого пространства офлайн

- **GIVEN** пустое пространство сохранено и приложение подготовило офлайн-ресурсы
- **WHEN** приложение закрыто и повторно запущено без сети
- **THEN** сохранённая вкладка открывается с пустым состоянием без демонстрационных окон

#### Scenario: Создание первого документа из пустого состояния

- **GIVEN** открыта пустая вкладка «Дашборд»
- **WHEN** пользователь открывает каталог из пустого состояния и создаёт чек-лист или план
- **THEN** документ открывается в окне текущей вкладки
- **AND** после сохранения и перезагрузки восстановлены созданное окно и документ
