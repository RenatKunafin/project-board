# Архив изменений

Здесь сохраняются требования, решения и численные результаты завершённых задач. Бинарные скриншоты удалены из текущего дерева при уборке PBT-060; исторические снимки доступны в git-истории (базовый коммит73f48c9363469b2508b7feaf5c69c10cac2373d2). Старые команды/пути в отчётах описывают окружение эксперимента, а не обещают наличие удалённых стендов сегодня.

Новые изображения, trace и логи записываются в test-results/ или прикладываются к PR. Принятые численные raw остаются неизменными. Текущие инструкции запуска находятся в корневом README и docs/.
