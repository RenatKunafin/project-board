# PBT-073 — Проектный Гантт: тёмная тема, тулбар и зум

## Why

Платформа и каркас уже в тёмной теме по токенам прототипа (PBT-069–072), но проектный Гантт остаётся в светлой теме Willow с дефолтным оформлением SVAR: белый чарт на тёмном окне, кнопки тулбара одним primary-стилем в одну строку, нет зума шкалы. Попутно закрываются два зафиксированных техдолга: SVAR тянет `wx-icons.css` с cdn.svar.dev внешним запросом (нарушение офлайн-PWA, находка PBT-069) и сброс прокрутки шкалы при развороте окна (design D8 PBT-071). Референс: прототип `flexi-dashboard-hub` (`SvarGanttChart.tsx`, `GanttPrototype.tsx`, `styles.css` — блок `.svar-gantt .wx-willow-dark-theme`); скриншоты `screenshots/redesign-ref/01`, `07`–`10`.

## What Changes

- **Тёмная тема SVAR:** обёртка `Willow` → `WillowDark` + полный набор `--wx-*` переопределений на семантические токены по прототипу (задачи `primary`, сводные `success`, связи `muted-foreground`→`primary` при наведении, праздники `warning`, выходные `muted`, mono-шкала, радиус полос 3px, без теней). Непрозрачный фон sticky-шкалы (фикс PBT-053) сохраняется.
- **Иконки SVAR локально:** `WillowDark fonts={false}` + вендоринг `wx-icons.css`/`wx-icons.woff2`/`wx-icons.woff` в `packages/gantt/src/vendor/wx-icons/` — внешний запрос к cdn.svar.dev устраняется (офлайн-требование PWA).
- **Техдолг D8 (PBT-071):** позиция прокрутки шкалы сохраняется при изменении размеров окна (разворот/восстановление, resize) — пассивный трекинг `scrollLeft` + разовое восстановление после стабилизации ширины; при смене зума — конверсия позиции через дни (подробности и отличие от отвергнутых в D8 PBT-071 подходов — design D6).
- **Колонки таблицы:** «Начало»/«Конец» — формат дд.мм моно-шрифтом (по прототипу); «Исполнители» и остальные колонки — без изменений.
- **Тулбар в две строки (прототип):** строка 1 — «+ Задача» (primary), «+ Группа» (ghost), разделитель, «Импорт», «Экспорт», «PlantUML», иконка «Настройки плана», справа «⚠ Проблемы N» (warning при наличии, иначе приглушённая); строка 2 — поиск с иконкой (фильтр PBT-049), селект ресурса, **сегмент зума «Дни/Недели»** (cellWidth 48 ↔ 33; состояние — settings экземпляра через `updateSettings`, переживает перезапуск), справа счётчик «N задач». Иконки lucide (`lucide-react@0.575.0` точным пином в `packages/gantt`, прецеденты PBT-069/072). Все `data-*`-атрибуты и aria-labels команд сохраняются (e2e).
- **Футер-статус виджета:** слева — название плана, справа — служебный статус последнего действия (`role="status"`).
- **Единый стиль диалогов модуля** (форма задачи, форма группы, настройки плана/справочники, проблемы, импорт `.gantt`, преобразование в отпуск, экспорт PlantUML): max-width xl (576px), `surface`, заголовок + строка описания по образцу Dialog прототипа; структура и поведение форм не меняются.
- Жесты, схема ADR-5, ядро — без изменений (карточка).

## Impact

- **Код:** `packages/gantt/src/PlanGanttWidget.tsx` (тема, тулбар, футер, зум, прокрутка, колонки), `gantt.css` (SVAR-тема, тулбар, футер) + перенос стилей тулбара из `task-editor.css`, новый `vendor/wx-icons/` (css + 2 шрифта), диалоги (`TaskEditorDialog`, `GroupEditorDialog`, `ResourceCatalogDialog`, `PlanIssuesDialog`, `OnlineGanttImportDialog`, `AbsenceConvertDialog`, `PlantUmlExportDialog` — только разметка шапки/описания и css), `packages/gantt/package.json` (+`lucide-react@0.575.0` пин).
- **Тесты:** новые e2e — зум (переключение + reload), сохранение прокрутки при развороте; регресс существующих жестовых спек (смена темы/компоновки не должна ломать координатные жесты — проверки по data-атрибутам и полосам сохраняются); unit там, где появится логика (конверсия позиции зума).
- **Скриншоты до/после:** оба зума, диалоги, узкое (1024×778) и широкое окно.
