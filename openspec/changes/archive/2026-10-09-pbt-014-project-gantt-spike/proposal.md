# PBT-014 — Проверить компонент проектного Гантта (спайк SVAR)

## Why

До интеграции Гантта нужно принять решение о компоненте проектного представления (PBT-017). Первый кандидат — SVAR React Gantt, открытая MIT-редакция — не проверен прототипом на согласованных правилах редактирования (ADR PBT-003): собственная рабочая длительность, включительное окончание, ручные даты без автопереноса. Спайк закрывает главный технический риск ветки Гантта до начала ядра (PBT-030+).

## What Changes

- Добавляется изолированное экспериментальное приложение `apps/gantt-spike` (Vite), не входящее в продуктовую сборку `apps/project-board` и отдельные команды корня.
- В спайке — минимальный адаптер: контрольные данные PBT-012 (`tests/fixtures/gantt/small-plan.json`) → модель SVAR; редактирование перехватывается (`api.intercept()`), а не отдавается библиотеке.
- Проверяются пункты DoD карточки: drag/resize одной задачи без изменения дат зависимых; праздник меняет рабочую длительность, сохраняя границы, и нерабочие дни видны; включительное окончание корректно в таблице, полосе, форме и событиях; вложенные группы, FS-связь, resize контейнера; зафиксированы использованные API и лицензии.
- Итог — отчёт `.docs/research/PBT-014.md`: версии, окружение, команды воспроизведения, наблюдения, ограничения и вывод «подходит / подходит с ограничениями / не подходит», включая возможный отказ от кандидата.
- Продуктовый код (`apps/project-board`, `packages/*`) не изменяется; delta specs отсутствуют (`skip_specs: true`).

## Capabilities

### New Capabilities

- Нет: research-задача без изменения продуктового поведения.

### Modified Capabilities

- Нет.

## Non-goals

- Выбор и продуктовая интеграция компонента — только решение PBT-017; экспериментальный код не становится production-кодом.
- Ресурсные дорожки (React Calendar Timeline) — отдельный спайк PBT-015.
- Нагрузочные замеры на 500 задачах — PBT-016 (сценарий A из PBT-012).
- Продуктовый импорт `.gantt` и ядро планирования — PBT-030+; фикстурный конвертер PBT-012 остаётся fixtures-only.
- Коммерческая редакция SVAR не рассматривается: встроенные календари, ресурсы, undo/redo считаются недоступными.

## Impact

- Новые файлы: `apps/gantt-spike/**` (временное приложение; судьба после PBT-017 — удалить или включить решением), `.docs/research/PBT-014.md`.
- Новая зависимость: SVAR React Gantt (MIT) — только в `apps/gantt-spike`, не попадает в сборку `apps/project-board`.
- Корневые скрипты: возможно добавление команды запуска спайка (например, `dev:spike`) и его typecheck — перечень уточняется в design.md.
