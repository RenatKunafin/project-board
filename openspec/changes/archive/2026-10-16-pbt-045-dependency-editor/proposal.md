# PBT-045 — Редактор FS-зависимостей

## Why

FS-зависимости реализованы в ядре (PBT-035: защита циклов, лаги, дубли), связи отображаются стрелками (PBT-037), но редактировать их из приложения нельзя — только dev-хуком. Конфликты (PBT-046) без редактора зависимостей нечем вызвать.

## What Changes

- Секция «Предшественники (FS)» в форме задачи (режим редактирования): список предшественников с лагами (инлайн-изменение лага), добавление (селект задачи + лаг) и удаление связи.
- Команды применяются немедленно (не ждут «Сохранить» формы): `createDependency`/`updateDependency`/`deleteDependency` через колбэк, исполняемый ядром в `commitPlan` виджета; ошибки ядра (самоссылка, цикл, дубликат, invalid-lag, гонки) — сообщением у строки, документ не меняется.
- UI сознательно не фильтрует кандидатов-предшественников: попытка самоссылки/цикла/дубликата выполняется и отклоняется ядром с объяснением (DoD-3).
- Стрелки обновляются существующим механизмом пересборки представления после записи (remount по ревизии для записей формы).
- Проверка ADR PBT-003 C5: изменение связи (лаг через праздник) не меняет даты задач; временное нарушение сохраняется как ручной конфликт (диагностика `dependencyViolations` — предмет PBT-046).

## Impact

- Изменённые: `packages/gantt/src/TaskEditorDialog.tsx` (секция), `packages/gantt/src/PlanGanttWidget.tsx` (applyDependencyCommand); e2e `tests/e2e/dependencies.spec.ts`.
- Ядро не расширяется; delta specs — `task-dependencies`, `project-gantt` (стрелки).
- Разблокирует: PBT-046 (список и подсветка конфликтов).

## Non-Goals

- Создание связи жестом (стрелкой по полосе) — карточка явно допускает закрытие задачи без жеста; отдельная задача при потребности.
- Подсветка нарушенных зависимостей на шкале (PBT-046).
- Типы связей кроме FS (исключены решениями).
