## ADDED Requirements

### Requirement: Регистрация связанного виджета ближайших событий

Приложение SHALL регистрировать встроенный тип «Ближайшие события» с уникальным идентификатором, компонентом списка и документной поддержкой модуля `calendar`, типа `calendar`, схемы 1 и фабрикой того же содержимого календаря. Добавление типа через каталог SHALL использовать штатный выбор существующего документа или создание нового документа календаря; содержимое SHALL оставаться общим с виджетом «Календарь».

#### Scenario: Тип виден в каталоге

- **WHEN** пользователь открывает каталог виджетов
- **THEN** видит тип «Ближайшие события» с описанием списка событий и может добавить его на вкладку

#### Scenario: Выбор существующего календаря

- **GIVEN** существует документ календаря «Личный календарь»
- **WHEN** пользователь добавляет «Ближайшие события» и выбирает этот документ в платформенном каталоге
- **THEN** создаётся экземпляр списка с `documentId` выбранного документа без копирования содержимого

#### Scenario: Создание нового календаря

- **WHEN** пользователь при добавлении «Ближайшие события» создаёт новый документ с названием
- **THEN** платформа создаёт пустой документ `calendar` версии 1 и открывает список на этом документе
