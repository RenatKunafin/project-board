# PBT-022 — Каскадное размещение окон

## Why

После PBT-021 единственный режим размещения — сетка. Согласованное поведение (решения §4.3): каскад — свободное размещение с перекрытием окон, активное окно поднимается поверх остальных. Нужен второй layout-адаптер в паре с `TiledLayout`, чтобы PBT-023 ввёл переключение режимов над готовыми адаптерами, а PBT-024 сохранял обе раскладки.

## What Changes

- В `packages/dashboard` появляется адаптер `CascadeLayout`: кандидат react-rnd 10.5.3 (MIT, решения §19) изолируется за минимальным контрактом, как в `TiledLayout`.
- Свободный перенос за заголовок и resize за уголки с ограничениями из `sizeConstraints` типа (ячейки → пиксели константой адаптера); правило границ: окно не может быть вынесено за пределы области вкладки так, чтобы заголовок стал недостижим.
- Перекрытие разрешено; активация окна (клик по рамке, PBT-020) поднимает его на верх стека; порядок глубины хранится в приложении и сериализуется.
- Сворачивание согласовано: свёрнутое окно сжимается до заголовка, разворачивание возвращает прежний размер (ADR-7 PBT-002).
- Раскладка — собственная структура: `areas` (`instanceId → {x, y, width, height}` в пикселях) + `order` (порядок глубины по `instanceId`); запись после завершённой операции (решения §15.4); персистентность — PBT-024.
- Временное решение (заменяется PBT-023): минимальный переключатель «Сетка / Каскад» в приложении для проверки каскада; раздельные раскладки режимов и их сохранение при возврате не входят в этот PR.
- Delta spec: capability `widget-layouts` дополняется требованиями каскада.

## Capabilities

### New Capabilities

- Нет.

### Modified Capabilities

- `widget-layouts` — ADDED: свободное размещение с ограничениями, перекрытие и порядок глубины, сериализация каскадной раскладки.

## Non-goals

- Переключение режимов как продуктовое поведение: раздельные раскладки тайлинга/каскада, сохранение при возврате к режиму — PBT-023 (здесь — временный тумблер без раздельного хранения).
- Персистентность раскладки и порядка (PBT-024); приостановка отрисовки перекрытых окон (PBT-027).
- Выравнивание/раскладка по сетке в каскаде, привязка к направляющим.
- Стилистика под макеты (PBT-066).

## Impact

- Новые файлы: `packages/dashboard/src/cascade-layout.ts`, `packages/dashboard/src/CascadeLayout.tsx` + тесты; delta spec `specs/widget-layouts/spec.md`.
- Изменённые: `packages/dashboard/src/index.ts`, `packages/dashboard/package.json` (react-rnd), `apps/project-board/src/App.tsx` (переключатель режимов, состояние каскада, порядок глубины), `apps/project-board/src/index.css`, e2e.
- Готовит почву: PBT-023 (переключение режимов), PBT-024 (восстановление обеих раскладок).
