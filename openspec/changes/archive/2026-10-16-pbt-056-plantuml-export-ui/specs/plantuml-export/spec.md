## ADDED Requirements

### Requirement: Экспорт PlantUML из интерфейса с предпросмотром

Представление плана SHALL предоставлять команду экспорта PlantUML: перед скачиванием пользователю показывается предпросмотр — полный сгенерированный текст диаграммы и перечень ограничений из отчёта генератора. Из предпросмотра SHALL быть доступно скачивание файла с именем по шаблону `pb-plantuml-YYYY-MM-DD_HH-mm-ss.puml` и копирование текста в буфер обмена там, где его поддерживает окружение. Экспорт SHALL работать офлайн, использовать весь документ плана независимо от фильтров и состояний представления и MUST NOT изменять документ, его ревизию или локальные настройки виджета. Инструкция в предпросмотре SHALL разделять самодостаточный текст PlantUML и требования конкретной инсталляции Confluence (макрос/плагин подключает получатель).

#### Scenario: Предпросмотр показывает текст и ограничения

- **GIVEN** открыт план с FS-зависимостями с лагами (непереносимая семантика)
- **WHEN** пользователь открывает экспорт PlantUML
- **THEN** предпросмотр содержит полный текст диаграммы, начинающийся с открывающего тега и заканчивающийся парным закрывающим
- **AND** ограничения перечислены рядом с текстом

#### Scenario: Скачивание даёт файл генератора

- **GIVEN** открыт план
- **WHEN** пользователь скачивает из предпросмотра
- **THEN** браузер предлагает файл с именем вида `pb-plantuml-YYYY-MM-DD_HH-mm-ss.puml`
- **AND** содержимое файла совпадает с показанным текстом

#### Scenario: Фильтры не влияют на экспорт

- **GIVEN** в окне плана активен текстовый фильтр, скрывающий часть задач
- **WHEN** выполняется экспорт
- **THEN** текст содержит все задачи документа, включая скрытые фильтром
- **AND** фильтр и остальные настройки виджета остаются без изменений

#### Scenario: Экспорт не меняет документ

- **GIVEN** открыт план
- **WHEN** пользователь открывает предпросмотр и отменяет его
- **THEN** документ, его ревизия и содержимое остаются без изменений

#### Scenario: Копирование текста

- **GIVEN** открыт предпросмотр экспорта
- **WHEN** пользователь нажимает копирование
- **THEN** текст диаграммы попадает в буфер обмена, если окружение его поддерживает; при отсутствии поддержки пользователь может выделить текст вручную
