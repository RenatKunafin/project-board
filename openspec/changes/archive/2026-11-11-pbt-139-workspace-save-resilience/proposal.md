# PBT-139 — Устойчивая запись рабочего пространства при активной работе

## Why

PBT-138 установила механизм потери данных: снапшот workspace записывается debounce-ом 300 мс с отменой таймера, эффект в `App.tsx` не имеет зависимостей и перезапускает таймер на каждом рендере. При непрерывной активности (ввод, перетаскивание — рендеры чаще ~3 Гц) запись откладывается бесконечно: окна и вкладки живут только в памяти, аварийное завершение без `pagehide` теряет их. Воспроизведено стендом (серия D, 5/5 потерь окон).

## What Changes

- Механизм отложенной записи снапшота выносится из `App.tsx` в чистый модуль платформы с инъекцией таймеров.
- Добавляется потолок ожидания: при непрерывных изменениях ожидание запуска записи не превышает `MAX_WAIT` (2 с) с первого несохранённого изменения серии; завершение и ошибки отслеживаются отдельно.
- Структурные операции (создание/удаление окна, вкладки, переименование вкладки, смена режима размещения, замена документа окна) записываются немедленно.
- Посторонние рендеры App не перезапускают сохранение; полный снимок сохраняет актуальную геометрию.
- Уход вкладки в фон (`visibilitychange → hidden`) форсирует запись отложенного снапшота.
- Delta spec `local-persistence` (MODIFIED «Запись снапшота после изменений»).
- Проверки: unit модуля записи (управляемые таймеры), e2e на фактическую запись в БД при непрерывном вводе, локальный kill-стенд серии D как регресс.

## Capabilities

### New Capabilities

- Нет.

### Modified Capabilities

- `local-persistence`: требование «Запись снапшота после изменений» получает потолок ожидания, немедленную запись структурных операций и форсаж при уходе в фон.

## Non-goals

- Автоснапшоты и восстановление при пересоздании БД браузером (PBT-140).
- Изменение автосохранения документов (DocumentService).
- Новые хранилища и схемы БД.

## Impact

- `packages/dashboard/src/` (новый модуль записи + экспорт), `apps/project-board/src/App.tsx` (использование модуля), unit/e2e тесты.
- Продуктовое поведение раскладки не меняется; меняется только гарантия своевременности записи.
