## Context

См. `proposal.md`. PBT-095 уменьшила дневную клетку до 24px; `shared-plan-gestures` по-прежнему перемещает указатель на 96px. В чистом `develop` этот файл даёт 7/10, а одинаковый production JS hash в `develop` и кандидате заметок подтверждает, что PBT-101 не является причиной.

## Goals / Non-Goals

**Goals:**
- Описывать жест в тесте количеством календарных дней, а не устаревшим пиксельным расстоянием.
- Сохранить проверку реальных mouse events и прежний ожидаемый сдвиг дат на два дня.

**Non-Goals:**
- Менять физическое поведение полос при движении мыши.
- Перенастраивать масштабы и даты планирования.

## Decisions

- В тестовом helper задавать желаемое смещение в календарных днях, затем вычислять пиксельный delta через существующую `zoomPxPerDay('days')` из `packages/gantt/src/zoom-utils`. Сейчас 2 дня = 48px. Это одна функция, используемая приложением для перевода масштаба в пиксели на день; при будущем изменении масштаба тест сохранит тот же смысл жеста.
- Использовать вычисленный delta и для обычного завершения, и для отпускания вне чарта. Сохранить hit-testing полосы, количество промежуточных mousemove, задержки, ожидания сверок, даты, ревизии и assertions соседних задач.
- Не менять публичный API пакета Gantt ради теста: e2e импортирует существующий внутренний utility по относительному пути. Если utility переедет, импорт compile-time укажет на обновление helper.
- Не добавлять delta spec или менять ADR: сценарии не меняют продуктовый контракт. `.openspec.yaml` объявляет `skip_specs: true` для test-only scope.

## Risks / Trade-offs

- [Риск] Тест зависит от внутреннего пути utility → он находится в том же репозитории и typecheck/build e2e выявят перемещение; публичный API ради одного теста не расширяется.
- [Риск] Сдвиг в календарных днях может отличаться от рабочих дней вокруг выходных → сохраняются прежние заданные start/end и проверяется реальный результат по текущим правилам планирования.

## Migration Plan

Миграции и изменения runtime нет. Откат возвращает прежний helper с фиксированными 96px и известные семь падений при масштабе 24px.
