## Why

Чек-лист — первый настоящий модуль и проверка границы платформа/модуль на живом потребителе ([ADR PBT-002](../../../../docs/adr/PBT-002.md), этап 1 решений): документ списка в `DocumentService` (PBT-007), компонент через `WidgetProps`, два экземпляра — одни данные. Заодно закрывает SDK v0 п.2: контекст экземпляра получает ссылку на документ.

## What Changes

- `packages/widget-sdk`: контракт `DocumentService` переносится из dashboard (модули обязаны работать с документами через SDK, а не через внутренности платформы — DoD); `WidgetProps` дополняется опциональными `documentId` и `documentService`.
- `packages/checklist` (первый настоящий код модуля): содержимое документа `{ items: [{ id, text, done }] }`; чистые операции `addItem / renameItem / setItemDone / removeItem` (иммутабельные); компонент `ChecklistWidget` — добавление, переименование, отметка, удаление; определение типа `checklist` через `defineWidgetType`.
- `apps/project-board`: демонстрационный виджет PBT-006 удаляется; приложение создаёт один документ чек-листа в сервисе и подключает тип `checklist`; оболочка показывает каталог (1 тип) и два экземпляра одного документа (проверка согласованных данных).
- Тесты: unit операций модели и «модель не зависит от React/платформы»; e2e: редактирование списка в браузере, два экземпляра показывают одни данные.
- Инварианты: пустой текст не создаёт пункт; пустой список — определённое состояние; два списка — независимы.

## Capabilities

### New Capabilities

- `checklists`: документ списка и операции над пунктами — создание (непустой текст), переименование, отметка выполнения, удаление; согласованность между экземплярами через общий документ.

### Modified Capabilities

- `widget-registry`: контракт `WidgetProps` дополняется опциональными `documentId` и `documentService` (ссылка на документ в контексте экземпляра — SDK v0 п.2, ADR-6.2); существующие требования не меняются, сценарии остаются валидными.

## Impact

- `packages/widget-sdk/src` (перенос `DocumentService`, расширение `WidgetProps`), `packages/checklist/` (модуль), `packages/dashboard/src` (реализация импортирует контракт из SDK), `apps/project-board/src` (замена демо на чек-лист, два экземпляра).
- Вход для PBT-010 (автосохранение поверх операций чек-листа), PBT-011 (два представления списка), PBT-019 (каталог).
- Демо-виджет PBT-006 удаляется вместе со своими e2e-проверками.
