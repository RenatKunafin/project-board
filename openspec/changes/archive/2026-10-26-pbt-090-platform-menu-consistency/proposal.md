## Why

Карточка PBT-090: панели платформы (каталог виджетов, каталог документов, выбор документа) не следуют единым UX-правилам, принятым в PBT-085/PBT-089 для диалогов и меню модуля Гантта: нет кламп-размещения у краёв экрана, нет возврата фокуса на кнопку, подтверждение удаления не объясняет последствий для открытых представлений.

## What Changes

- `DropdownPanel` платформы: размещение у кнопки-якоря с clamp к viewport (края экрана, доступная высота, разворот вверх при нехватке места), прокрутка длинного содержимого; закрытие по Escape и клику вне с возвратом фокуса на кнопку-якорь; при открытии фокус переходит первому полю панели.
- Семантика остаётся честной: панели с поиском/полями — `role=dialog` без перехвата стрелок (список команд — прежние кнопки); никакого `role=menu` интерактивным панелям.
- Подтверждение удаления документа объясняет последствия: сколько представлений документа открыто и что все они перейдут в состояние недоступного документа; закрытие окна и удаление документа остаются разными действиями.
- Существующее сохраняется: создание/поиск/переименование/выбор, состояния каталога (пусто/фильтр/ошибка загрузки), защита будущей версии, недоступность фоновых панелей при модальном редакторе (нативный верхний слой).
- Отдельная платформенная реализация: без импорта меню модулей и без общего SDK-сервиса/нового UI-пакета.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `document-management`: каталог документов — размещение панели и клавиатура; удаление — объяснение последствий.
- `widget-registry`: панель каталога виджетов и выбор документа — те же правила размещения и фокуса.

## Impact

`packages/dashboard/DropdownPanel.tsx` (позиционирование, фокус), `DocumentCatalogPanel.tsx` (текст подтверждения), CSS приложения. Модули и SDK не затрагиваются; API платформы не расширяется.

## Non-Goals

Общий UI-пакет или SDK API модалок, `role=menu` для панелей с полями, изменения модели документов и состояний каталога, перехват стрелок в панелях, меню модулей.
