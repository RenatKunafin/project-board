## MODIFIED Requirements

### Requirement: Каталог документов

Платформа SHALL предоставлять каталог документов: список всех документов по метаданным (название, модуль-владелец, тип документа) с фильтром по зарегистрированным типам документов и счётчиком окон, открытых с документом на всех вкладках. Из каталога SHALL выполняться создание документа выбранного типа через фабрику модуля и открытие документа в экземпляре подходящего зарегистрированного типа на активной вкладке; повторное открытие уже открытого документа SHALL создавать ещё одно представление того же содержимого. Каталог MUST NOT проверять поля содержимого конкретных модулей. Панель каталога SHALL размещаться у своей кнопки с учётом краёв экрана и доступной высоты (целиком в viewport, длинное содержимое прокручивается), закрываться по Escape и клику вне с возвратом фокуса на кнопку, а при открытии передавать фокус первому полю панели.

#### Scenario: Каталог перечисляет документы по метаданным

- **GIVEN** существуют документы модулей `checklist` и `gantt` с названиями
- **WHEN** пользователь открывает каталог документов
- **THEN** отображаются все документы с их названиями и типами из метаданных

#### Scenario: Каталог показывает счётчик открытых окон

- **GIVEN** документ «Покупки» открыт в двух окнах на разных вкладках
- **WHEN** пользователь открывает каталог документов
- **THEN** строка документа «Покупки» показывает, что он открыт в двух окнах

#### Scenario: Фильтр по типу документа

- **GIVEN** каталог открыт без фильтра и показывает документы двух типов
- **WHEN** пользователь выбирает фильтр по типу «чек-лист»
- **THEN** отображаются только документы этого типа, документы других типов скрыты

#### Scenario: Открытие документа из каталога

- **GIVEN** существует закрытый документ «Покупки» типа чек-листа
- **WHEN** пользователь открывает его из каталога на активной вкладке
- **THEN** появляется экземпляр зарегистрированного типа чек-листа с этим документом

#### Scenario: Повторное открытие создаёт второе представление

- **GIVEN** документ «Покупки» уже открыт в одном экземпляре
- **WHEN** пользователь снова открывает его из каталога
- **THEN** на активной вкладке появляется второе представление с тем же содержимым

#### Scenario: Размещение и клавиатура панели каталога

- **GIVEN** окно приложения небольшой высоты, у пользователя есть 30 документов
- **WHEN** пользователь открывает каталог и прокручивает список
- **THEN** панель целиком находится в viewport, список прокручивается внутри панели, фокус при открытии — в поле фильтра
- **AND** Escape закрывает панель и возвращает фокус на кнопку каталога

### Requirement: Удаление документа

Удаление документа SHALL быть отдельной операцией каталога с подтверждением пользователя. Подтверждение SHALL объяснять последствия: количество открытых представлений документа и их переход в состояние недоступного документа. При подтверждении сервис SHALL удалить документ из состояния памяти и хранилища вместе с отложенными записями; документ перестаёт отображаться в каталоге и не восстанавливается после перезапуска. Отмена подтверждения MUST NOT изменять документ. Экземпляры, открывшие удалённый документ, SHALL перейти в состояние недоступного документа. Закрытие окна виджета и удаление документа — разные действия: закрытие окна MUST NOT удалять документ.

#### Scenario: Подтверждённое удаление убирает документ

- **GIVEN** документ «Покупки» существует и не открыт ни в одном окне
- **WHEN** пользователь подтверждает удаление
- **THEN** документ исчезает из каталога и хранилища и не появляется после перезапуска

#### Scenario: Удаление при открытом окне

- **GIVEN** документ «Покупки» открыт в окне на активной вкладке
- **WHEN** пользователь подтверждает удаление документа
- **THEN** документ удаляется, окно переходит в состояние недоступного документа, остальные окна работают

#### Scenario: Подтверждение объясняет последствия для представлений

- **GIVEN** документ «Покупки» открыт в двух окнах
- **WHEN** пользователь запускает удаление из каталога
- **THEN** подтверждение называет документ, количество открытых представлений и их переход в состояние недоступного документа

#### Scenario: Отмена удаления ничего не меняет

- **GIVEN** открыт запрос подтверждения удаления документа «Покупки»
- **WHEN** пользователь отменяет подтверждение
- **THEN** документ остаётся в каталоге и хранилище, открытые окна продолжают показывать содержимое
