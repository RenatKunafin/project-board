## Why

Виджеты работают с документом, а не с внутренними таблицами платформы (раздел 3.1 решений): один план/список может быть открыт в нескольких виджетах, и изменение должно достигать всех представлений. Для этого нужен универсальный сервис документов с подписками — пока в памяти (IndexedDB приходит в PBT-009). Схема полей документа зафиксирована в решениях (15.2): `id, moduleId, documentType, schemaVersion, revision, createdAt, updatedAt, content`; защита целостности — проверка `revision` (15.4). Сервис закрывает SDK v0 п.3 «Работа с документами и уведомления» ([ADR PBT-002](../../.docs/adr/PBT-002.md)).

## What Changes

- `packages/widget-sdk`: контракт документов — `ManagedDocument` (поля по 15.2, content — `unknown`), `DocumentConflictError` (обновление по устаревшей редакции), типы подписок `DocumentSubscribe`/`Unsubscribe`; фабрики вида `defineDocumentType(moduleId, documentType)`.
- `packages/dashboard`: реализация `createDocumentService()` — в памяти: создание/чтение/обновление с проверкой `expectedRevision`, подписка/отписка, синхронные уведомления новой редакцией после фиксации операции; отдельное хранилище настроек представления по экземпляру виджета (`viewSettings`).
- Тесты сервиса: последовательные обновления с уведомлением двух подписчиков, отписка, независимость документов по id, конфликт устаревшей редакции, отдельность `viewSettings`.
- Правил чек-листа и Гантта в сервисе нет: `content` — непрозрачное значение владельца-модуля.
- Подключение в приложении не выполняется — интеграция с виджетами начнётся в PBT-008 (модуль чек-листа станет первым потребителем).

## Capabilities

### New Capabilities

- `document-management`: жизненный цикл документов в сервисе платформы — создание/чтение/обновление, редакции и конфликты, подписки/отписки, независимость документов, отдельное состояние представления.

## Impact

- `packages/widget-sdk/src` (типы контракта), `packages/dashboard/src` (реализация и тесты).
- Вход для PBT-008 (чек-лист как первый потребитель), PBT-009 (замена in-memory реализации на IndexedDB без смены контракта), PBT-010 (автосохранение поверх сервиса).
- Продуктовый UI и оболочка не меняются.
