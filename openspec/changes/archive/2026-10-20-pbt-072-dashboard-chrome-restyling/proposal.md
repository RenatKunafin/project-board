# PBT-072 — Каркас дашборда: топ-бар, вкладки, панели

## Why

Токены, рамка окна и максимизация готовы (PBT-069–071), но каркас приложения сохранил компоновку каркаса PBT-004/023: нет топ-бара (название — заголовок в потоке, индикатор сохранения сжат в строку вкладок), вкладки — «язычки» без прототипного акцента, переключатель раскладки — две отдельные кнопки, панели каталогов — плотные списки без карточек и описаний, пустое состояние — текст без действия. Прототип `flexi-dashboard-hub` задаёт целевой вид каркаса (скриншоты `screenshots/redesign-ref/01`, `03`–`06`, `11`).

## What Changes

- **Топ-бар** (h-44px, `chrome`): иконка-лого (`LayoutDashboard`, primary) + название приложения; справа — индикатор состояния сохранения документов (переносится из строки вкладок; подписи статусов прежние). **Уточнение реализации (design D9):** индикатор стал сводным по всем документам — прежде он следил только за документом среза «Список 1»; платформенный сервис документов получает `getAggregateSaveStatus`/`subscribeAggregateSaveStatus` (не SDK).
- **Панель вкладок** (h-40px, `chrome`): активная вкладка — фон канваса + верхняя полоса акцента `primary`; неактивные — приглушённые с hover; закрытие/перемещение проявляются по hover вкладки (доступность с клавиатуры сохраняется). Кнопка «+» — в стиле прототипа.
- **Сегмент-контрол «Сетка/Каскад»** (общая рамка, активный сегмент `accent`) — вместо двух отдельных кнопок; поведение прежнее (режим — свойство вкладки).
- **Панели каталогов** в стиле прототипа (`popover` + `shadow-float` уже с PBT-069): каталог виджетов — карточки с иконкой-плиткой, названием и **описанием типа**; каталог документов — строки с иконкой-плиткой типа, inline-переименованием и счётчиком **«открыт в N окнах»** (данные `panesByTab`), удаление — по hover; пикер документов — тем же языком.
- **SDK**: опциональное поле `description` в `WidgetTypeDefinition` (тексты типов: «Диаграмма Ганта: задачи, сроки, зависимости» и т.п. по прототипу) — обратимосовместимое расширение контракта.
- **Шапка вкладок:** кнопки «Документы»/«+ Виджет» — ghost с иконками lucide (design D11); хром фиксированной высоты (design D10, фикс сжатия).
- **Пустое состояние канваса**: иконка в круге, «Пустой дашборд», подсказка и кнопка **«Добавить виджет»** (открывает каталог виджетов).

Не входит (карточка): статус-бар (часы/wifi прототипа — декор); демо-метрики топ-бара и пользователь с аватаром (нет данных в модели); переименование окна.

### Modified Capabilities

- `workspace-tabs`: ADDED «Топ-бар рабочего пространства» (название приложения + индикатор состояния сохранения); MODIFIED «Создание и переключение вкладок» (+визуальное выделение активной вкладки).
- `widget-registry`: MODIFIED «Регистрация типа виджета при сборке» (опциональное описание типа) + сценарий карточки каталога с описанием.
- `document-management`: MODIFIED «Каталог документов» (+счётчик открытых окон) + сценарий.

## Impact

- **Код:** `apps/project-board/src/App.tsx` (топ-бар, перенос save-state, пустое состояние + callback), `index.css` (топ-бар, вкладки, сегмент, карточки панелей, пустое состояние), `packages/dashboard/src/{WidgetCatalogPanel,DocumentCatalogPanel,DocumentPickerPanel,EmptyWorkspace}.tsx`, `packages/widget-sdk/src/index.ts` (+`description?`), `packages/dashboard/src/document-service.ts` (сводный статус записи, D9), `apps/project-board/package.json` (`lucide-react@0.575.0` точным пином, D11), тексты описаний в модулях `gantt`/`checklist`.
- **Тесты:** e2e — топ-бар/индикатор, счётчик окон, описание в каталоге, пустое состояние; существующие aria-локаторы сохраняются (правки стилевые + разметка карточек); полный набор.
- **Референс:** `flexi-dashboard-hub/src/components/dashboard/Dashboard.tsx` (header, nav, Popover, пустое состояние), скриншоты `screenshots/redesign-ref/`.

## Non-Goals

- Статус-бар приложения (часы, счётчик виджетов, wifi) — вне карточки, отдельное будущее решение.
- Демо-метрики спринта/релиза/рисков и пользователь с аватаром — нет данных в модели.
- Двухшаговый мастер добавления виджета из прототипа — текущий поток (тип → документ) сохраняется, меняется только оформление.
- Переоформление содержимого виджетов — PBT-073–075.
