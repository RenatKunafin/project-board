# PBT-075 — Чек-лист: оформление, прогресс и скрытие выполненных

## Why

Финальная задача серии редизайна PBT-072–075: каркас, рамки окон, Гантт и ресурсный вид уже в тёмной теме по прототипу, чек-лист остаётся со служебным оформлением (checkbox-настройка «Скрывать выполненные», текстовая кнопка «Добавить», крестик-удаление всегда видим) и без прогресса. Обе фичи включены решением владельца 2026-10-19. Референс: прототип `flexi-dashboard-hub`, `src/components/dashboard/widgets.tsx` (`TodoWidget`); скриншот `screenshots/redesign-ref/01-dashboard-overview.png` (правое окно). Попутно закрывается ограничение текущей реализации: флаг «Скрывать выполненные» хранится через in-memory `setViewSettings` платформенного сервиса и не переживает перезапуск — карточка требует persisted-состояние экземпляра.

## What Changes

- **Шапка вида**: слева производный прогресс — «N/M выполнено (X%)» (X% моно-шрифтом) + полоса высотой 4px (`muted` → заполнение `success`); справа кнопка-чип «Скрыть выполненные» (toggle: активна — рамка `primary`, фон `primary/10`; неактивна — рамка `border`, приглушённая). Прогресс вычисляется из документа, модель не меняется.
- **Скрытие выполненных — состояние экземпляра через SDK `updateSettings({ hideDone })`** (persisted `view:<instanceId>`, механизм PBT-049): переживает reload, изолировано между экземплярами; In-memory `setViewSettings` из виджета убирается (метод платформы не трогаем).
- **Пункты**: hover-строка `accent`; чекбокс 16×16 `accent-primary`; выполненные — зачёркивание + `muted-foreground` (уже есть); кнопка удаления — иконка lucide `Trash2` 14px, видна при hover строки, hover — `destructive` (aria-label «Удалить: <текст>» сохраняется). Инлайн-переименование по двойному клику сохраняется.
- **Ввод**: поле на всю ширину (рамка `input`, фон `background`, фокус — `primary`) + компактная primary-кнопка «+» (иконка `Plus`, aria-label «Добавить»); Enter добавляет (форма уже сабмитится).
- **Стили пакета**: стили чек-листа переносятся из `apps/project-board/src/index.css` в `packages/checklist/src/checklist.css` (модуль владеет своими стилями, прецедент — css-файлы packages/gantt); значения — по прототипу, только токены.
- **Ревью PR#54, финальные правки (решения владельца)**: ручка изменения размера в обоих режимах — геометрия прототипа 1-в-1 (SVG-маска «M9 3 L3 9 M9 6 L6 9», stroke 1.2/10, `muted-foreground/70`), 16×16, отступ 1px от угла окна, в пределах окна (у каскада хэндл react-rnd `20×20, right/bottom −10px` центрирован на углу — маска привязана к углу окна, не хэндла); акцентная (голубая) рамка активного окна убрана — активное выделяется только плавающей тенью.
- Модель документа, автосохранение, миграции — без изменений; пустые состояния сохраняются.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `checklists`: ADDED «Прогресс и скрытие выполненных» (производный прогресс; скрытие — persisted-состояние экземпляра с изоляцией и переживанием reload).
- `app-theme`: MODIFIED «Тёмная тема приложения» (активное окно — тень без акцентной рамки, решение владельца ревью PR#54).
- `widget-windows`: MODIFIED «Рамка окна экземпляра» (активное окно — тень; ручка ресайза по прототипу в обоих режимах, отступ от краёв окна).

## Impact

- **Код:** `packages/checklist/src/ChecklistWidget.tsx` (шапка, пункты, ввод, `updateSettings`), новый `packages/checklist/src/checklist.css` (перенос+редизайн стилей из `apps/project-board/src/index.css`).
- **Тесты:** e2e `shell.spec.ts` — «Скрывать выполненные» чекбокс → кнопка (2 теста), кнопка «Добавить» → aria-label сохранён; новые e2e — прогресс (значение/полоса после отметок), скрытие + reload (переживание настройки), изоляция экземпляров уже покрыта существующим тестом.
- **Скриншоты до/после:** виджет с выполненными пунктами, 1024×778 и широкое окно.

## Non-Goals

- Строка демо-метрик прототипа (спринт/релиз/риски) — не переносим (принцип серии).
- Модель документа (прогресс-поле, приоритеты, дедлайны) — не расширяется.
- Механизм `setViewSettings` платформенного сервиса — остаётся (используется ли другими модулями — вне задачи; SDK не меняем).
- Диалоги/тулбары других модулей, светлая тема — вне задачи.
