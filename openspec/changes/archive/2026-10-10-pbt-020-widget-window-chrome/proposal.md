# PBT-020 — Рамка окна, сворачивание и закрытие

## Why

После PBT-030 панели приложения рендерятся по реестру, но окно экземпляра не оформлено: заголовок — техническая строка «План · ОКАД» с единственной кнопкой «Закрыть», нет сворачивания, активного состояния и кнопок окна. Карточка требует единое оформление окна по макетам (`.context/layout/main.png`, `widget-resizing.png`); поведение рамки принадлежит платформе (границы ADR PBT-002). Это фундамент для тайлинга PBT-021, которому нужны заголовок-ручка переноса и свёрнутые окна в сетке.

## What Changes

- В `packages/dashboard` появляется общий компонент рамки окна `WidgetWindow`: заголовок (иконка типа, название экземпляра), кнопки «Свернуть»/«Развернуть»/«Закрыть», подсветка активного окна. Содержимое виджета — дети рамки; виджет не знает о chrome.
- Сворачивание: окно остаётся заголовком (по макету); содержимое скрывается `display:none` — компонент виджета остаётся смонтированным, локальное состояние представления сохраняется (ADR-7 PBT-002, без размонтирования). Разворачивание возвращает содержимое; размер восстанавливается автоматически (сетка приложения).
- Закрытие удаляет экземпляр из вкладки (сейчас панель лишь прячется в `closed`-множестве): документ и другие представления того же документа продолжают работать.
- Активное окно: клик по рамке делает окно активным, активное подсвечивается рамкой (по макету); состояние в памяти приложения.
- Доступность: кнопки окна подписаны (`aria-label` с названием экземпляра), достижимость с клавиатуры, видимый фокус; редактирование внутри виджета не перехватывается (кнопки только в заголовке).
- Состояние сворачивания/активности — в памяти приложения; персистентность раскладки — PBT-024 (вне границ).
- Delta spec: capability `widget-windows` дополняется требованиями рамки, сворачивания, активности и закрытия экземпляра.

## Capabilities

### New Capabilities

- Нет.

### Modified Capabilities

- `widget-windows` — ADDED: рамка окна и кнопки; сворачивание/разворачивание; активное окно; закрытие экземпляра с сохранением документа.

## Non-goals

- Перетаскивание за заголовок и изменение размеров окна (PBT-021 — тайлинг; уголок-подсказка размера из макета не реализуется до сетки).
- Перекрытие окон и каскад (PBT-022–023).
- Приостановка тяжёлой отрисовки свёрнутых окон (PBT-027; здесь только скрытие без размонтирования).
- Персистентность сворачивания/активности (PBT-024).
- Кнопки темы, поиска и добавления из заголовков макета (тема — PBT-066; остальные вне согласованного поведения).
- Изменения `widget-sdk` (события жизненного цикла 6.5 — отдельные решения по мере задач).

## Impact

- Новые файлы: `packages/dashboard/src/WidgetWindow.tsx` + тесты; delta spec в `openspec/changes/pbt-020-widget-window-chrome/specs/widget-windows/spec.md`.
- Изменённые: `apps/project-board/src/App.tsx` (панель оборачивается в рамку, состояние collapsed/active, закрытие = удаление экземпляра), `apps/project-board/src/main.tsx` (стабильное сопоставление панелей и документов в вертикальном срезе — см. design D7), `apps/project-board/src/index.css` (стили рамки), e2e-тесты.
- Разблокирует: PBT-021 (тайлинг использует заголовок и свёрнутые окна).
