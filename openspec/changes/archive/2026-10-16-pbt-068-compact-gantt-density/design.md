# Design — PBT-068 Компактная плотность Гантта

## Context

Замеры 2026-10-16 (DOM): наш проектный вид — день 100px (дефолт `cellWidth` SVAR), шаг строк 38px (дефолты `rowHeight` 44/52, фактический шаг по полосам 38), полоса 31px, шапка шкалы 73px. Референс OnlineGantt (onlinegantt.com, файл эталона): день ≈ 33px, строка 36px, полоса 22–27px. E2E жестов масштабонезависимы (`dayPx` вычисляется из ширины полосы, комментарии PBT-039 в `plan-gantt.spec.ts`).

## Goals / Non-Goals

Goals: компактный дефолт день/строка по референсу; жесты и подсветка не ломаются.

Non-Goals: zoom-кнопки проектного вида; ресурсный вид; таблица колонок и шрифты.

## Decisions

### D1. Значения: `cellWidth = 33`, `rowHeight = 36`

Пропсы компонента `Gantt` (SVAR): `cellWidth` задаёт клетку нижней шкалы (у нас unit «день» — клетка = день), `rowHeight` — высоту строки области задач и таблицы. 33/36 — фактические значения референса; DoD допускает отклонение до дня ≤ 40px / строки ≤ 36px, если живая проверка покажет проблемы читаемости конкретно у 33 (резерв: 36/36). Высота полосы — производная SVAR от строки; при 36px полоса ≈ 28px.

### D2. Проверяемые зоны риска

- **Однодневные полосы и `minWidth: 4`:** при дне 33px однодневная полоса 33px — текст в полосе помещается хуже; SVAR скрывает подпись при нехватке места (наблюдение PBT-037) — проверяется живой сессией.
- **Жесты:** порог срабатывания SVAR фиксирован в пикселях; переносы в e2e на 2–3 дня (66–99px) — выше порога; тест «drag с выходом за панель» имеет запас 250px ≈ 7 дней при 33px — контрольный прогон.
- **Диапазон шкалы:** фиксированный с запасом (min−60/max+365, PBT-039 D7) — при уменьшении клетки общая ширина шкалы в пикселях падает, `ensureChartRangeCovers` не меняется.

### D3. Механика проверки

`npm run build` → preview → MCP-браузер: замер DOM (день ≤ 40, строка ≤ 36), визуальная проверка шкалы/полос/подсветки, скриншот; затем полный набор (lint/typecheck/test/test:browser на чистой среде, openspec validate).

## Risks / Trade-offs

- [33px может оказаться тесно для подписей дней в шкале] → резерв 36px (DoD ≤ 40px), выбор фиксируется живой проверкой в этом же PR.
- [Скрытые пиксельные константы в CSS] → аудит `gantt.css` на жёсткие ширины, связ notions с днём (подсветка растянута на 100% — масштаб не важен).

## Migration Plan

Замена дефолта без миграций; откат — вернуть пропсы.
