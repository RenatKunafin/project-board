# PBT-068 — Компактная плотность Гантта

## Why

Проектный Гантт отображается крупнее референса OnlineGantt: ширина дня 100px (дефолт SVAR `cellWidth`) и шаг строк 38px дают ~10 дней в стандартном окне — владелец не видит достаточно контекста плана. Референс (замер DOM на onlinegantt.com, 2026-10-16, файл эталона): день ≈ 33px, строка 36px, полоса 22–27px.

## What Changes

- **Плотность по умолчанию** проектного вида: ширина дня и высота строки уменьшаются до значений референса — `cellWidth = 33`, `rowHeight = 36` (точные значения — design D1; критерий DoD: день ≤ 40px, строка ≤ 36px).
- Полосы задач и подсветка нерабочих дней масштабируются автоматически (высота полосы — производная строки); шапка шкалы и таблица колонок SVAR не меняются.
- Ресурсный вид (RCT) не затрагивается — у него собственная плотность и zoom (PBT-049).

### Modified Capabilities

## Impact

- **Код:** `packages/gantt/src/PlanGanttWidget.tsx` — два пропса компонента SVAR; возможна мелкая правка CSS (отступы полос) по результату живой проверки.
- **Тесты:** e2e масштабонезависимы (пиксели дня вычисляются из ширины полосы — комментарии PBT-039); полный набор контрольный.
- **Замеры:** до/после DOM + скриншот в `change/screenshots/`.

## Non-Goals

- Zoom-кнопки проектного вида (пресеты масштаба в UI) — отдельное решение, если компактного дефолта окажется мало.
- Плотность ресурсного вида, размеры таблицы колонок, шрифты приложения (темы — PBT-066).
