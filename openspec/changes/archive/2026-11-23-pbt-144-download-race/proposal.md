# PBT-144 — Гонка отзыва blob-URL при скачивании копии

## Why

При полном browser-прогоне PBT-143 дважды красным падал calendar-тест «серия календаря переносится общей копией и переживает offline reload» (только в наборе, не в изоляции). Диагностика: `WorkspaceBackupDialog.download()` вызывает `URL.revokeObjectURL(url)` синхронно сразу после `anchor.click()`. Браузер разыменовывает blob-URL асинхронно из другого процесса; выиграв гонку, отзыв делает скачивание молчаливно сорванным — события `download` нет, а UI уже показывает «Файл передан браузеру для скачивания». Дефект предсуществующий (PBT-064, 2026-10-28, PR#85), не связан с изменениями PBT-143. Воспроизведение: одиночный тест `--repeat-each=8` — 1 падение/8; в полном наборе под нагрузкой — 2/2. Для пользователя дефект означает: «Скачать» иногда не отдаёт файл, хотя интерфейс утверждает обратное.

## What Changes

- Отзыв blob-URL после клика по anchor откладывается на 1000 мс через `setTimeout` — по действующему прецеденту `PlanGanttWidget` (экспорт PlantUML): браузер гарантированно успевает начать скачивание, объектные URL копий (килобайты JSON) проживают секунду без заметной памяти.
- Стабилизируется poll calendar-теста «серия календаря переносится общей копией…»: после «Заменить пространство» приложение перезагружает страницу, и `page.evaluate` poll'а мог попасть в навигацию («Execution context was destroyed», класс ошибки уже фиксировался в диагностике PBT-139). Теперь ошибка навигации внутри poll трактуется как «ещё не готово»; итоговое утверждение не меняется. Тестовая гонка проявилась после фиксa скачивания — раньше тест не доходил до неё.
- Delta spec `workspace-backup` — MODIFIED «Скачивание и проверка JSON-файла»: инициированное скачивание не срывается молча.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `workspace-backup`: требование «Скачивание и проверка JSON-файла» явно запрещает молчаливый срыв скачивания; добавлен сценарий.

## Non-goals

- Изменение формата, имени файла и текста статуса диалога.
- Увеличение задержки в `notes/export` (там отзыв уже отложен — `setTimeout 0` + отзыв в `catch`; сбоев не наблюдалось).
- Механизм выбора файла «Из файла», история копий, автокопии в папку.

## Impact

- `apps/project-board/src/WorkspaceBackupDialog.tsx` — одна строка отзыва URL.
- Тесты: повтор calendar-теста как регресс (до/после), прогон workspace-backups, полный набор.
