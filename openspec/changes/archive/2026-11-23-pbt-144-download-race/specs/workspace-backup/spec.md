## MODIFIED Requirements

### Requirement: Скачивание и проверка JSON-файла

Пользователь SHALL иметь возможность скачать локальную копию в версионированный JSON и выбрать файл через «Из файла». Инициированное скачивание SHALL завершаться передачей файла браузеру: оно MUST NOT срываться молча после показа статуса передачи. Корректный файл SHALL открывать предпросмотр и подтверждение восстановления до любой замены данных. Файл отдельного плана, файл прототипа, повреждённый JSON и неподдерживаемый формат SHALL отклоняться понятной ошибкой. Скачанный файл SHALL быть пригоден для восстановления в чистом хранилище и офлайн. Выбор файла сам по себе MUST NOT создавать копии в локальной истории.

#### Scenario: Скачивание передаёт файл браузеру

- **GIVEN** в истории есть хотя бы одна копия
- **WHEN** пользователь нажимает «Скачать»
- **THEN** браузер получает файл копии (событие скачивания), а не только статус о передаче

#### Scenario: Перенос в чистое приложение

- **GIVEN** пользователь скачал копию пространства с несколькими документами и вкладками
- **WHEN** он выбирает этот файл в чистом приложении и подтверждает восстановление
- **THEN** доступны исходные документы, вкладки, общие ссылки окон, обе раскладки и настройки

#### Scenario: Ошибочный файл

- **GIVEN** выбран файл другого формата либо повреждённая копия
- **WHEN** приложение проверяет файл
- **THEN** показывается ошибка, а текущее пространство и история копий не меняются
