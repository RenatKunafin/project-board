# Design — PBT-137

## D1. Выбор даты события от «сегодня»

Окно виджета: `today … today + UPCOMING_DAYS(6)` включительно (`packages/calendar/src/upcoming.ts`). Тест создаёт событие без времени:

- базовый случай — `сегодня + 2 дня`: всегда внутри окна, не зависит от «сегодня» и не создаёт событие на граничную дату;
- стык месяца — если `сегодня + 2` выходит за пределы текущего месяца (сетка месяца показывает только его дни: `monthGrid` даёт `date: null` для соседних месяцев, а навигация по месяцам — вне объёма), событие создаётся на «сегодня»: по контракту фильтра событие сегодняшнего дня без времени включается в окно (`date !== today || event.time === ''`).

Покрытие ветвей: любой день года попадает в одну из двух ветвей; обе дают дату внутри окна — тест устойчив круглый год.

## D2. Селектор дня

Число дня уникально в сетке текущего месяца; кнопка дня содержит число первым текстовым узлом. Используется фильтр по точному числу (`^\s*<day>\s*$`) вместо прежнего `/^2/` — прежний фильтр совпадал с «2», «20»–«29» и брал первый подходящий, что и сделало тест дато-зависимым.

## D3. Границы

Продуктовый код не трогается; поведение приложения не меняется. Проверка — целевой тест и полный browser-набор; зелёность в любой день обеспечивается построением (D1), дополнительная имитация системной даты не вводится.
