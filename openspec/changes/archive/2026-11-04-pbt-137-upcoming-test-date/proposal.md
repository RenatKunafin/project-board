# PBT-137 — Устранить дато-зависимость теста «ближайшие события»

## Why

Тест `tests/e2e/calendar.spec.ts:88` создаёт событие на «2»-е число текущего месяца и ждёт его в виджете «ближайших 7 дней» (`UPCOMING_DAYS = 6`: сегодня … сегодня+6). Событие попадает в окно лишь ~8 дней в месяц (27-е … 2-е); с 03.11.2026 тест стабильно красный — воспроизведено на чистом develop в отдельном worktree. Продуктовый код корректен, дефект — в выборе даты тестом.

## What Changes

- Тест выбирает дату события вычисляемо от «сегодня»: `сегодня + 2 дня`, когда дата остаётся в текущем месяце сетки; на стыке месяцев — «сегодня» (событие без времени включается окном по контракту фильтра `upcoming.ts`).
- Селектор дня уточнён точным числом дня (сетка содержит только дни текущего месяца — `monthGrid` возвращает `date: null` для чужих).
- Продуктовый код, семантика окна и остальные тесты не изменяются; delta specs отсутствуют (`skip_specs: true`).

## Capabilities

### New Capabilities

- Нет: тестовый дефект без изменения продуктового поведения.

### Modified Capabilities

- Нет.

## Non-goals

- Изменение `packages/calendar` и семантики `UPCOMING_DAYS`.
- Аудит других тестов на дато-зависимость (отдельные находки при обнаружении).
- Навигация по месяцам в тесте.

## Impact

- `tests/e2e/calendar.spec.ts` (один тест, ~5 строк выбора даты).
- Артефакты change; реестр/карточка PBT-137.
