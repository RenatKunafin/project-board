# PBT-082 — Проверки реализации

Дата: 2026-10-24. База develop bcab82d, ветка feature/pbt-082-conflict-task-navigation. Дизайн одобрен владельцем до реализации.

## Результат

Вся запись проблемы — одна нативная кнопка, активируемая кликом/Enter/Space. Переход закрывает модалку, раскрывает предков, сбрасывает фильтры своего экземпляра и после применения props выбирает задачу с фокусом на полосу. Горизонтальная позиция берётся из фактической геометрии SVAR ($x), поэтому видно начало длинной полосы в Днях/Неделях. Прежние повторы восстановления прокрутки отменяются. Ожидающие rAF отменяются cleanup при смене документа/цели/видимости или размонтировании.

Собственная запись жеста сохраняет props, только пока фильтры и раскрытие групп не меняются. CSS совместимости включает штатное вертикальное смещение виртуальных строк и непрозрачную неподвижную шапку. Расчёт конфликтов, даты задач, SDK, схемы и зависимости не менялись.
