## Why

Первая продуктовая задача платформы: рабочее пространство строится вокруг вкладок — именованных независимых пространств размещения (решения 4.1). Без вкладок нет мест для каталога и окон (PBT-019+), а вертикальный срез PBT-011 показал жизнеспособность контракта SDK — теперь платформа получает собственный UI-каркас. Состояние обслуживается в памяти (персистентность пространства — PBT-024).

## What Changes

- `packages/dashboard`: чистая модель рабочего пространства `createWorkspaceState()` — иммутабельные операции `addTab / renameTab / moveTab / removeTab / setActive` + `WorkspaceError` (удаление последней вкладки, пустое имя, неизвестный id).
- `apps/project-board`: панель вкладок по макету — role="tablist", активная вкладка выделена, переименование по двойному клику (inline), закрытие «×», перемещение кнопками «←/→», создание кнопкой «+»; управление с клавиатуры (Tab/Enter/стрелки на фокусе списка).
- Независимый набор экземпляров на вкладку: первая вкладка содержит вертикальный срез PBT-011 (два экземпляра «Списка 1» и один «Списка 2»), новые вкладки — пустое состояние с подсказкой (каталог — PBT-019).
- Правила удаления: последнюю вкладку удалить нельзя; при удалении активной активной становится соседняя; документы при удалении вкладки сохраняются.
- Пустое состояние пространства — определённый компонент платформы.
- PBT-066 (дизайн-токены) выполняется отдельно: стили оболочки — на существующих токенах палитры, новых хекс-кодов не появляется.

## Capabilities

### New Capabilities

- `workspace-tabs`: именованные вкладки рабочего пространства — создание, переименование, переключение активной, изменение порядка, правила удаления (последняя не удаляется, активная → соседняя, документы сохраняются), независимость наборов экземпляров, доступность с клавиатуры.

## Impact

- `packages/dashboard/src` (модель вкладок, `EmptyWorkspace`), `apps/project-board/src` (панель вкладок, наборы экземпляров per-вкладка), e2e.
- Вход для PBT-019 (каталог и добавление экземпляров в активную вкладку), PBT-020 (рамки окон), PBT-024 (персистентность пространства).
- Контракты документов и чек-листа не меняются.
