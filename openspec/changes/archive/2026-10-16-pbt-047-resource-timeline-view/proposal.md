# PBT-047 — Ресурсные дорожки из документа плана

## Why

Согласованное ресурсное представление (§13.2 решений) — компактные дорожки исполнителей: когда ресурс занят, где окна, где конфликты. Ядро готово (назначения PBT-034, конфликты PBT-036), проектный Гантт на SVAR работает (PBT-037), но ресурсного вида в продукте нет — решение ADR PBT-017 ADR-2/ADR-4 (RCT 0.30.0-beta.19) не реализовано.

## What Changes

- Второй widgetType «Ресурсы» в `createGanttModule`: тот же документ plan (`moduleId: gantt`, `documentType: plan`), другой компонент — ресурсные дорожки на React Calendar Timeline. Два вида одного плана открываются одновременно как разные виджеты; изменение документа обновляет оба.
- Production-адаптер `resource-timeline-adapter.ts` с нуля (спайковый код не переносится, ADR-6): ресурсы → группы дорожек; назначения → элементы на дорожке каждого ресурса (D1); неназначенные задачи не отображаются (D2); отпуск → элемент недоступности у своего ресурса без жестов; включительное окончание → полночь дня после окончания (A1).
- Подсветка календаря плана: выходные дни недели и праздники — на общей шкале (праздник различим), рабочее исключение — без подсветки.
- Конфликты из ядра (`resourceConflicts`, PBT-036) отмечаются на дорожках: конфликтные интервалы/элементы визуально отличимы от допустимых пересечений (Разработка+ПСИ — не конфликт).
- Представление v1 только читает документ: жесты drag/resize — PBT-048; API беты изолируется в модуле адаптера.
- Попутная чистка (прецедент pbt039dbg → PBT-040): удаление отладочного `console.info('[pbt046dbg] …')` из `PlanGanttWidget.tsx` — остаток PBT-046, просочившийся в коммит 383b9ae.

## Impact

- Новые файлы: `packages/gantt/src/resource-timeline-adapter.ts` (+тест), `packages/gantt/src/ResourceTimelineWidget.tsx`, `packages/gantt/src/resource-timeline.css`.
- Изменённые: `packages/gantt/src/index.ts` (второй widgetType), `packages/gantt/src/PlanGanttWidget.tsx` (чистка console.info), `packages/gantt/package.json` (точные пины `react-calendar-timeline@0.30.0-beta.19`, peer `dayjs`, `interactjs`).
- E2E `tests/e2e/resource-timeline.spec.ts`.
- Delta spec — новая capability `resource-timeline`.

## Non-Goals

- Жесты drag/resize и открытие формы на дорожках (PBT-048); редактирование вообще.
- Лента занятости ресурса (union-полоса интервалов) — в DoD не входит; решение владельца 2026-10-15: ресурсное отображение — в рамках этого отдельного виджета, лента не включается; при потребности — отдельный код PBT.
- Фильтры, масштаб, сохранение состояния представления (PBT-049).
- Переназначение задач между дорожками; дорожка «Без ресурса» (D2, §13.2).
