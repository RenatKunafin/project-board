# PBT-049 — Фильтры и настройки представлений

## Why

Каждый экземпляр виджета имеет собственные настройки отображения (§5 решений): масштаб, фильтры, раскрытие групп, прокрутка. Сейчас состояние представления (сворачивание групп PBT-040, фильтров нет) живёт только в памяти и теряется при перезапуске; два виджета одного плана не могут быть настроены независимо. Последняя задача представлений перед финалом серии.

## What Changes

- Минимальный набор фильтров (уточнение владельца в карточке): **текст задачи** (подстрока без учёта регистра) и **ресурс** (выбор из справочника). Фильтры в обоих видах; фильтрация — производный рендер: документ не меняется, скрытые задачи участвуют в проверках (список проблем PBT-046, конфликты PBT-036 считаются по полному плану).
- Сохранение состояния экземпляра (ADR-6.4 PBT-002 — «чтение/запись состояния экземпляра»): SDK получает `updateSettings(patch)` в `WidgetProps`; платформа хранит состояние в таблице `settings` под ключом `view:<instanceId>` (generic-KV — без новой версии схемы БД) и отдаёт снапшот при монтировании панели. Сохраняется: фильтры (оба вида), раскрытие/сворачивание групп (проектный), масштаб и видимая область (ресурсный, zoom-кнопки + контролируемый видимый диапазон).
- Пустое состояние фильтра: явная подсказка в обоих видах (DoD-4).
- «Показать» из списка проблем (PBT-046) сбрасывает фильтры — задача может быть скрыта фильтром.
- DoD-5 (открытие дополнительного представления без дублирования документа) обеспечивается существующим пикером каталога (PBT-025, проверено e2e PBT-047) — фиксируется тестом в связке с состоянием.

## Impact

- SDK: `WidgetProps.updateSettings` (частичный патч, платформа мержит) — реализация ADR-6.4.
- Dashboard: `WorkspaceStore.loadViewSettings/saveViewSetting` (таблица `settings`, ключи `view:*`); `App` — `initialViewStates` (bootstrap до рендера), хранилище в стабильном ref (не дёргает memo TabSurface), прокидывание в `WidgetPane`.
- Gantt: план-виджет (тулбар-фильтры, фильтрация дерева задач/групп, collapsedGroups → settings), ресурсный виджет (фильтры, zoom-кнопки + контролируемый видимый диапазон → settings, пустое состояние).
- E2E `tests/e2e/gantt-view-state.spec.ts`.

## Non-Goals

- Масштаб проектного вида (SVAR): зум-механика SVAR не исследована спайком; шкала фиксирована (D7 PBT-039). При потребности — отдельная задача с исследованием.
- Прокрутка шкалы в сохраняемом состоянии (обе: прокрутка RCT входит в видимую область; SVAR-прокрутка вне v1) — DoD требует масштаб/фильтры/раскрытие групп.
- Фильтры по типу работы, датам, статусу — вне минимального набора.
