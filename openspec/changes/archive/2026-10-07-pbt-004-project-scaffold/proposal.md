## Why

Все продуктовые задачи (PBT-006 и далее) предполагают коммиты кода в существующие пакеты: модуль чек-листа, SDK, платформу. Пока нет запускаемого каркаса с закреплёнными командами dev/build/typecheck, каждая задача начинала бы с настройки окружения. Технические решения уже приняты ([ADR PBT-002](../../../../docs/adr/PBT-002.md)): React + TypeScript + Vite, npm workspaces, структура `apps/` + `packages/`. Осталось воплотить их в минимально работающий скелет.

## What Changes

- Создать монорепо npm workspaces: `apps/project-board` (PWA-оболочка Vite + React + TS) и четыре пакета `packages/dashboard`, `packages/widget-sdk`, `packages/gantt`, `packages/checklist`.
- Закрепить направления зависимостей по ADR-3: модули → `widget-sdk`; `dashboard` не импортирует предметные модули; `widget-sdk` не зависит от пакетов проекта.
- Приложение запускается (`dev`), показывает пустую оболочку с заглушкой платформы; production-сборка (`build`) даёт статические ресурсы; `preview` открывает собранную страницу.
- Настроить `typecheck` по всем пакетам (единый TS-конфиг базовый + пакетные), закрепить версии зависимостей и `packageManager` (npm), создать `package-lock.json`.
- Обновить корневой README: точные команды установки, dev, build, preview, typecheck; проверить воспроизводимость чистой установкой.
- Места подключения модулей (реестр типов) определить как точку расширения без фиктивной реализации функций.
