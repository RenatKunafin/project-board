# PBT-038 — Создание и редактирование задач через форму

## Why

Ядро команд плана (PBT-031) не имеет UI: задачи нельзя создать, переименовать, перенести по датам или удалить из приложения — только dev-хуком. Проектный Гантт (PBT-037) — просмотр. Форма — базовый путь редактирования для всех последующих UI-задач (назначения PBT-042, зависимости PBT-045) и первый подключённый к ядру редактор.

## What Changes

- В виджете проектного Гантта: тулбар «Добавить задачу», форма задачи (диалог поверх чарта), редактирование по двойному клику строки задачи, удаление из формы.
- Форма работает только командами ядра: `createTask`, `updateTask` (название/группа), `setTaskDates` (даты из рабочей длительности), `deleteTask`. Ядро не расширяется.
- Поля: название, группа (селект: корень + группы), начало (дата), рабочая длительность (дни ≥ 1) с показом вычисленного окончания; ошибки домена — у соответствующего поля.
- Read-only ограничение PBT-037 снимается точечно: остаётся запрет на перемещение полос (PBT-039), форма — отдельный механизм.

## Impact

- Новые файлы: `packages/gantt/src/TaskEditorDialog.tsx`, `packages/gantt/src/task-editor.css` (var()-токены), unit-тесты формы-логики; e2e `tests/e2e/plan-editor.spec.ts`.
- Изменённые: `packages/gantt/src/PlanGanttWidget.tsx` (тулбар, открытие формы, двойной клик), `packages/gantt/src/index.ts` (экспорт), `apps/project-board/src/index.css` (токены диалога при необходимости).
- Даты: ввод через `addWorkingDays(start, duration − 1)` (ядро PBT-013) → `setTaskDates`; окончание в форме показывается включительно. Сохранение дат не переносит соседние задачи (контракт ядра).
- Изменения применяются через SDK-подписку — второй экземпляр виджета обновляется по `revision` (механизм PBT-037).
- Разблокирует: PBT-039 (drag/resize), PBT-042, PBT-045; серия PBT-038–049 делается в одной ветке одним PR (директива владельца 2026-10-14).

## Non-Goals

- Drag/resize полос (PBT-039), назначение ресурсов/типов (PBT-042), зависимости (PBT-045), группы UI (PBT-040).
- Форма группы (PBT-040); селект группы в форме задачи — только выбор существующей.
- Undo/история операций.
