## ADDED Requirements

### Requirement: Явный выбор ресурса при преобразовании импортированных строк

При преобразовании импортированной строки без исполнителя в период недоступности ресурс SHALL определяться только явным выбором пользователя из справочника плана: значение MUST NOT предугадываться по названию записи или иным данным строки. Список предлагаемых ресурсов — справочник текущего плана; при пустом справочнике преобразование предлагает сначала создать ресурсы.

#### Scenario: Неоднозначное имя не влияет на выбор

- **GIVEN** импортированная строка «ОТПУСК-DEV-iOS» и два ресурса «iOS-разработчик» и «iOS-разработчик 2»
- **WHEN** пользователь открывает преобразование и выбирает «iOS-разработчик 2»
- **THEN** период недоступности создаётся именно для выбранного ресурса
- **AND** выбор ресурса изначально пуст: подсказки из названия строки нет

#### Scenario: Пустой справочник подсказывает создать ресурсы

- **GIVEN** задача без исполнителей в плане без ресурсов
- **WHEN** пользователь открывает преобразование
- **THEN** диалог сообщает об отсутствии ресурсов и не предлагает применения
