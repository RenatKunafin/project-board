## ADDED Requirements

### Requirement: Преобразование задачи в период недоступности

Модуль SHALL предоставлять преобразование задачи в период недоступности ресурса: по явной команде пользователя создаётся один период недоступности с датами из диалога преобразования и выбранным ресурсом, а исходная задача удаляется целиком — вместе с назначениями и ссылками зависимостей на неё. Преобразование SHALL выполняться атомарно: частичное применение (период без удаления задачи или удаление без периода) недопустимо. Отмена диалога преобразования MUST NOT изменять план; повторное преобразование уже преобразованной строки невозможно, поскольку строка удаляется. Другие задачи MUST NOT переноситься.

#### Scenario: Преобразование создаёт период и удаляет исходную задачу

- **GIVEN** план с задачей без исполнителей и зависимостью, ссылающейся на неё
- **WHEN** пользователь выбирает ресурс, проверяет даты и применяет преобразование
- **THEN** в плане появляется один период недоступности с выбранным ресурсом и датами из диалога
- **AND** исходная задача и зависимость на неё отсутствуют, остальные задачи не изменились

#### Scenario: Назначения задачи удаляются вместе с ней

- **GIVEN** задача с назначенными исполнителями
- **WHEN** пользователь применяет преобразование для одного из ресурсов
- **THEN** создаётся один период недоступности выбранного ресурса
- **AND** задача и все её назначения отсутствуют в плане

#### Scenario: Отмена сохраняет исходную строку

- **GIVEN** открыт диалог преобразования задачи
- **WHEN** пользователь отменяет его
- **THEN** план остаётся без изменений: задача, её зависимости и периоды недоступности — прежние

#### Scenario: После преобразования работают дорожка и конфликт

- **GIVEN** период недоступности создан преобразованием, и у ресурса есть назначенная работа, пересекающаяся с ним по рабочим дням
- **WHEN** отображаются ресурсное представление и список проблем
- **THEN** на дорожке ресурса виден период недоступности
- **AND** список проблем содержит конфликт пересечения работы с отпуском без изменения дат задач

#### Scenario: Перевёрнутые даты отклоняются по месту

- **GIVEN** в диалоге преобразования окончание раньше начала
- **WHEN** пользователь применяет преобразование
- **THEN** отображается ошибка, план не изменяется
