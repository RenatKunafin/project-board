# planning-conflicts (delta) — PBT-046 Conflict presentation

## ADDED Requirements

### Requirement: Список проблем плана

Проектный Гантт SHALL отображать единый список проблем плана, различая типы: нарушение FS-зависимости, пересечение двух непараллелизуемых работ одного ресурса, пересечение работы с отпуском исполнителя. Каждая запись SHALL содержать задачи, ресурс (когда применимо), рабочие даты пересечения и понятную причину. Список SHALL пересчитываться из документа без создания записей документа.

#### Scenario: Различение типов проблем

- **GIVEN** в плане нарушена FS-связь, у ресурса пересекаются две непараллелизуемые работы, а параллелизуемая работа пересекается с его отпуском
- **THEN** список проблем содержит три записи разных типов с задачами, ресурсом, датами и причинами

#### Scenario: Пересчёт без записи

- **WHEN** пользователь исправляет исходные данные (сдвигает задачу, удаляет отпуск)
- **THEN** соответствующая проблема исчезает из списка во всех экземплярах представления, а количество редакций документа соответствует только исправляющим операциям

### Requirement: Переход к задаче из списка

Из записи списка с задачей SHALL быть доступен переход к этой задаче: свёрнутые группы-предки раскрываются, шкала прокручивается к дате задачи, строка выделяется. Переход SHALL работать и для задачи внутри свёрнутой группы.

#### Scenario: Переход к задаче в свёрнутой группе

- **GIVEN** конфликтующая задача находится внутри свёрнутой группы
- **WHEN** пользователь нажимает «Показать» у записи списка
- **THEN** группа раскрывается, шкала прокручивается к задаче, задача выделяется

### Requirement: Правило параллельности без ложных срабатываний

Список проблем SHALL не помечать пересечение работ, где хотя бы одна имеет тип с разрешённой параллельностью, и SHALL помечать пересечение работы с отпуском её исполнителя независимо от параллельности работы.

#### Scenario: Разработка и ПСИ не конфликтуют, ПСИ в отпуске — конфликтует

- **GIVEN** ресурсу назначены непараллелизуемая «Разработка» и параллелизуемая «ПСИ» с пересекающимися датами, «ПСИ» пересекается с отпуском ресурса
- **THEN** в списке нет конфликта работ «Разработка»/«ПСИ», но есть конфликт типа «Отпуск исполнителя» для «ПСИ»
