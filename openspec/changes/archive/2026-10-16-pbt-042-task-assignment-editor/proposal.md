# PBT-042 — Назначение ресурсов и типов задачам

## Why

Справочники получили редакторы (PBT-041), но назначить ресурс или тип задаче из приложения нельзя — только dev-хуком. Без назначений ресурсное представление (PBT-047) и конфликты в UI (PBT-046) не имеют данных. Назначения — предмет карточки задачи (форма PBT-038).

## What Changes

- В форме задачи: секции «Исполнители» и «Типы работы» — чекбоксы по справочникам текущего плана (несколько назначений — D1 ADR PBT-003); «Без исполнителя» отображается явно, когда пусто.
- Сохранение — командами ядра: `createTask` (с assigneeIds/workTypeIds) или `updateTask` (патч множеств; пустое множество снимает все назначения — поле убирается). Даты не затрагиваются (контракт ядра).
- **Попутное выравнивание ядра (вне исходных границ карточки):** `updateTask` теперь убирает поле `assigneeIds`/`workTypeIds` при пустом патче-множестве — перенос контракта PBT-034 «опустевший массив убирается» с `unassign*` на прямой патч формы (+ регрессионный тест). Без этого снятие всех назначений из формы оставляло `[]` в документе.
- В таблице Гантта — колонки «Исполнители» (имена через запятую) и «Типы» (названия типов); неназначенная задача показывается «—» без дублирования строки.
- DoD-5 «не предлагает ёмкость пула» — UI не содержит процентов/ёмкостей (как в PBT-041 D7).

## Impact

- Изменённые: `packages/gantt/src/TaskEditorDialog.tsx` (секции чекбоксов, submit), `packages/gantt/src/PlanGanttWidget.tsx` (submitTaskForm — передача множеств, колонки таблицы); e2e `tests/e2e/task-assignments.spec.ts`.
- Ядро не расширяется; delta specs — `resource-planning`, `project-gantt`.
- Разблокирует: PBT-046 (конфликты в UI), PBT-047 (ресурсные дорожки).

## Non-Goals

- Назначение перетаскиванием между дорожками (PBT-047/048), отпуска (PBT-043), ёмкость пула (отклонена, §11.1).
- Отдельная карточка назначения вне формы задачи.
