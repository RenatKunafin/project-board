# project-gantt (delta) — PBT-042 Task assignment editor

## ADDED Requirements

### Requirement: Отображение назначений в таблице Гантта

Таблица проектного Гантта SHALL отображать назначенных исполнителей (имена из справочника плана) и типы работ каждой задачи; задача без назначений SHALL отображаться явно (прочерк). Задача с несколькими исполнителями SHALL отображаться одной строкой со списком исполнителей.

#### Scenario: Назначения видны в таблице и во втором экземпляре

- **GIVEN** задаче назначен исполнитель «QA»
- **WHEN** назначение изменено в форме задачи
- **THEN** таблица показывает нового исполнителя в этом экземпляре и во втором экземпляре того же документа после обновления по ревизии
