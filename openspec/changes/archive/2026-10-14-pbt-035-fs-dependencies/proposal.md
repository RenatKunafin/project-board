# PBT-035 — FS-зависимости и их проверка

## Why

Формат плана v1 хранит FS-зависимости (`dependencies: [{ id, fromTaskId, toTaskId, lagDays }]`), но операции над ними отсутствуют: связать задачи нельзя, а структурная целостность графа поддерживается только валидатором чтения. Нарушения сроков (C5) никто не вычисляет — без этого невозможны подсветка в проектном Гантте (PBT-037/046) и список конфликтов (PBT-046). Задача закрывает последний крупный слой ядра: команды создания/изменения/удаления FS-зависимостей с защитой графа от циклов (C4) и чистую диагностику временных нарушений с рабочим лагом (C1–C2) — без какого-либо исправления расписания.

## What Changes

- В `packages/gantt` добавляется модуль `plan-dependencies.ts`: команды `createDependency` (с идемпотентностью точного дубля), `updateDependency` (смена лага), `deleteDependency` и чистая функция `dependencyViolations(plan): DependencyViolation[]`.
- Семь новых команд не требуются — три команды; объединение `PlanCommand` расширяется тремя вариантами, диспетчер — тремя case'ами. Новые коды отклонений: `invalid-lag` (не целое < 0 — C2), `circular-dependency` (самоссылка и косвенный цикл — C4), `duplicate-dependency` (ребро существует с другим лагом), `unknown-dependency`.
- Лаг интерпретируется по `addWorkingDays` модуля PBT-013: лаг 0 — ближайший рабочий день после включительного окончания предшественника (C1), лаг N — ещё N рабочих дней; праздники внутри задержки учитываются автоматически.
- Диагностика нарушений — на ребро: `DependencyViolation { dependencyId, fromTaskId, toTaskId, expectedStart, actualStart, message }`; даты задач не изменяются (C5), поздние начала допустимы (ручной план).
- Концы существующего ребра не редактируются: изменение связи — удалить и создать (design D2); лаг меняется операцией.
- Delta spec: новая capability `task-dependencies`.

## Capabilities

### New Capabilities

- `task-dependencies` — FS-зависимости между задачами с рабочим лагом: команды с защитой графа, диагностика временных нарушений.

### Modified Capabilities

- Нет.

## Non-goals

- Автоперенос или выравнивание зависимых задач (раздел 7 решений — исключено; C5).
- Зависимости на группы, отрицательный лаг (C2/C3 — исключены из первой версии).
- Отображение связей на диаграмме (PBT-037), список конфликтов в UI (PBT-046), редактор зависимостей (PBT-045).
- Проверки ресурсных конфликтов (PBT-036).
- Изменения платформы и SDK; формат v1 не расширяется.

## Impact

- Новые файлы: `packages/gantt/src/plan-dependencies.ts`, `packages/gantt/src/plan-dependencies.test.ts`.
- Изменённые: `packages/gantt/src/plan-commands.ts` (3 варианта `PlanCommand`, 4 кода), `packages/gantt/src/index.ts` (экспорт).
- Прямых изменений приложения и платформы нет.
- Завершает ядро планирования; разблокирует PBT-036 (конфликты ресурсов — по тому же шаблону диагностики), PBT-037/045/046 (отображение и редактирование).
