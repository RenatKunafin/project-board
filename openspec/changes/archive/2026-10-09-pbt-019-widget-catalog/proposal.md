## Why

Каталог — способ добавления виджетов из макета («Добавление виджета»): пользователь выбирает зарегистрированный тип, платформа создаёт экземпляр на активной вкладке. Реестр типов готов (PBT-006), вкладки готовы (PBT-018) — остался связующий UI и контракт документных типов (создать новый документ или открыть существующий — решения, раздел 5: «один документ — несколько представлений»).

## What Changes

- `packages/widget-sdk`: `WidgetTypeDefinition` дополняется опциональными `icon` (текстовый символ) и `documentSupport` — дескриптор документного типа `{ moduleId, documentType, schemaVersion, createContent(title) }`; контракт остаётся без runtime-зависимостей.
- `packages/checklist`: тип получает иконку и `documentSupport` (создание содержимого чек-листа с названием); содержимое `ChecklistContent` дополняется опциональным `title` (операции модели сохраняют остальные поля).
- `apps/project-board`: кнопка «Добавить виджет» на панели вкладок → каталог зарегистрированных типов (overlay по макету «Добавление виджета»); клик по типу:
  - без документной поддержки — экземпляр сразу добавляется на активную вкладку;
  - с документной поддержкой — диалог «Новый чек-лист» (поле названия) или «Открыть существующий» (список документов модуля из хранилища); отмена не создаёт документов.
- Созданный/выбранный экземпляр появляется на активной вкладке со стартовыми настройками и ограничениями размеров из определения.
- Unit: модель чек-листа сохраняет `title` при операциях; e2e: каталог → новый список из пустой вкладки, второе представление существующего, отмена.

## Capabilities

### New Capabilities

- `widget-windows`: размещение экземпляров на активной вкладке — добавление из каталога, уникальный экземпляр с настройками по умолчанию и ограничениями размеров, второе представление одного документа.

### Modified Capabilities

- `widget-registry`: определение типа дополняется иконкой и опциональным дескриптором документной поддержки (модуль предоставляет фабрику нового содержимого); существующие требования регистрации и контракта пропсов не меняются.

## Impact

- `packages/widget-sdk/src` (типы), `packages/checklist/src` (иконка, дескриптор, title), `apps/project-board/src` (каталог, диалог, наборы панелей per-вкладка).
- Вход для PBT-020 (рамка окна и перетаскивание), PBT-025 (каталог документов).
- Документы и автосохранение работают как раньше (создание нового списка проходит через `DocumentService.create` → очередь автосохранения).
