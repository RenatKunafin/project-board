## ADDED Requirements

### Requirement: Добавление экземпляра из каталога

Платформа SHALL отображать каталог зарегистрированных типов виджетов (название и иконку) и добавлять экземпляр выбранного типа на активную вкладку по выбору пользователя. Экземпляр SHALL получать настройки по умолчанию и ограничения размеров из определения типа, а его идентификатор SHALL быть уникальным.

#### Scenario: Добавление экземпляра на активную вкладку

- **GIVEN** активна вкладка «План ОКАД», каталог содержит тип «Чек-лист»
- **WHEN** пользователь выбирает тип «Чек-лист» без документной поддержки
- **THEN** на вкладке «План ОКАД» появляется новый экземпляр с настройками по умолчанию и ограничениями размеров из определения

### Requirement: Выбор документа для документного типа

Для типа с документной поддержкой платформа SHALL предлагать выбор: создать новый документ (с названием, заданным пользователем) или открыть существующий документ этого модуля и типа. Отмена выбора MUST NOT создавать документы и экземпляры. Открытие уже открытого документа SHALL создавать второе представление того же содержимого.

#### Scenario: Создание нового чек-листа из пустой вкладки

- **GIVEN** активна пустая вкладка
- **WHEN** пользователь выбирает в каталоге «Чек-лист» и создаёт новый чек-лист с названием «Покупки»
- **THEN** создаётся документ модуля чек-листа с этим названием и на вкладке появляется экземпляр с пустым списком

#### Scenario: Второе представление существующего документа

- **GIVEN** существует документ «Покупки», уже открытый в одном экземпляре
- **WHEN** пользователь добавляет ещё один экземпляр «Чек-листа» и открывает документ «Покупки»
- **THEN** на вкладке появляется второе представление с тем же содержимым

#### Scenario: Отмена добавления

- **GIVEN** открыт диалог выбора документа для типа «Чек-лист»
- **WHEN** пользователь отменяет диалог
- **THEN** ни новый документ, ни экземпляр не создаются
