## Purpose

Даёт команде устойчивый журнал изменений по версиям и позволяет пользователю читать описание выпуска в приложении, в том числе после обновления и без сети.

## ADDED Requirements

### Requirement: Ведение журнала выпусков

Репозиторий SHALL содержать release notes, сгруппированные по выпущенным версиям и пригодные для отображения в приложении. Запись выпуска SHALL включать версию и пользовательские изменения; служебные детали реализации не SHALL подменять описание пользовательской ценности.

#### Scenario: Подготовка очередного выпуска
- **WHEN** команда подготавливает новую версию к публикации
- **THEN** она может добавить запись с версией и изменениями, сохранив записи предыдущих выпусков

### Requirement: Просмотр журнала в приложении

Приложение SHALL предоставлять доступ к журналу изменений из настроек рядом с резервным копированием. Представление SHALL позволять прочитать записи выпусков с версией и содержанием.

#### Scenario: Открытие из настроек
- **GIVEN** журнал содержит хотя бы один выпуск
- **WHEN** пользователь выбирает «Что нового» в настройках
- **THEN** приложение показывает журнал версий и их изменения

#### Scenario: Просмотр без доступных записей
- **GIVEN** журнал не содержит записей
- **WHEN** пользователь открывает «Что нового»
- **THEN** приложение показывает понятное пустое состояние без ошибки

### Requirement: Доступность журнала офлайн

Журнал выпусков SHALL быть доступен в подготовленной PWA без подключения к сети.

#### Scenario: Открытие журнала без сети
- **GIVEN** PWA подготовлена для автономной работы и журнал включён в текущую версию
- **WHEN** пользователь открывает журнал без сети
- **THEN** записи, поставляемые с этой версией приложения, отображаются полностью
