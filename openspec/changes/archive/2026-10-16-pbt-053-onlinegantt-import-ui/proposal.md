# PBT-053 — Предпросмотр и импорт `.gantt`

## Why

Парсер OnlineGantt `.gantt` готов (PBT-052: `parseOnlineGanttFile` с отчётом импорта), но воспользоваться им из приложения нельзя: кнопка импорта (PBT-051) принимает только собственный формат и `.gantt`-файлы отвергает. Согласованный сценарий обмена (решения §16) требует выбора файла, показа результата разбора до применения и создания нового плана.

## What Changes

- **Одна команда импорта, два формата:** кнопка «Импорт плана» 📥 (PBT-051) расширяется — `.json` собственного формата работает как сейчас (валидация → мгновенное создание), файл `.gantt` открывает **диалог предпросмотра**. Роутинг — по расширению выбранного файла; `accept` пополняется `.gantt`.
- **Диалог предпросмотра** (новый компонент в `packages/gantt`, паттерн существующих диалогов): редактируемое название плана (предзаполнено именем файла), сводка разбора (задачи/группы/ресурсы/зависимости/задачи без исполнителя), перечень предупреждений отчёта импорта (пропуски записей и связей, неперенесённые поля и настройки, сверка длительностей), список задач без исполнителя с пометкой «требуют ручного решения» (назначить исполнителя или преобразовать в отпуск — PBT-054), примечания исходного файла — текстом. Кнопки «Импортировать»/«Отмена», Esc — отмена.
- **Применение:** создаётся новый независимый документ плана (механика PBT-051: `documentService.create` + `switchDocument`, прежние планы не трогаются), окно переключается на импортированный план; успех — inline-сообщение под тулбаром.
- **Критические ошибки** (`invalid-json`/`invalid-structure` парсера) — inline-диагностика по месту, как у собственного формата: документ не создаётся, частичного плана нет. Отмена предпросмотра и закрытие диалога ничего не меняют.
- Пометка «требуют ручного решения» выставляется по отсутствию исполнителя (сводка `unassignedTasks` парсера), не по имени записи: автоматическое распознавание отпуска исключено (ADR PBT-003 D7).

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `plan-transfer`: ADDED — «Импорт файла OnlineGantt из интерфейса с предпросмотром» (выбор файла, предпросмотр до создания, применение/отмена, критические ошибки без документа) и «Состав предпросмотра импорта» (сводка разбора, предупреждения отчёта, задачи без исполнителя как ручные решения без удаления, примечания текстом).

## Impact

- **Код:** `packages/gantt` — новый компонент диалога предпросмотра + правки `PlanGanttWidget.tsx` (роутинг расширения, состояние предпросмотра); платформа, SDK и ядро не меняются (`switchDocument` — PBT-051).
- **Тесты:** e2e `tests/e2e/` (полный импорт эталона с проверкой дат/связей в обоих представлениях, отмена предпросмотра, ошибочный вход, повторный импорт — два независимых документа); unit — чистая логика предзаполнения названия и форматирования отчёта, если появится.
- **CSS:** токены `:root`, без хексов (до PBT-066).
- **Границы:** DoD карточки покрывается e2e на эталонных файлах из `tests/fixtures/gantt/`.

## Non-Goals

- Преобразование отпуск-строк в периоды недоступности и выбор ресурса — PBT-054 (сейчас строки без исполнителя остаются задачами).
- Правка импортированных данных внутри предпросмотра (переименование задач, назначения, правка дат) — предпросмотр только показывает результат и название; правки — после импорта обычными средствами.
- Импорт `.gantt` из ресурсного вида (тулбар только у проектного Гантта — как PBT-051; новый план доступен любому виджету через каталог документов).
- Экспорт в `.gantt` (обмен с OnlineGantt однонаправленный).
