## ADDED Requirements

### Requirement: Командные операции над задачами

Модуль планирования SHALL предоставлять единый набор чистых операций над задачами плана: создание, изменение полей, ручной ввод дат, перенос, ввод длительности и удаление — применяемые к содержимому плана и возвращающие либо новое содержимое, либо отклонение с кодом причины. Отклонённая операция MUST NOT изменять план. Операции MUST NOT изменять идентификаторы существующих сущностей. Идентификатор создаваемой задачи SHALL генерироваться модулем и быть уникальным в плане.

#### Scenario: Создание задачи не меняет соседей

- **GIVEN** план с двумя задачами и зависимостью между ними
- **WHEN** создаётся новая задача с корректными датами
- **THEN** результат содержит новую задачу с уникальным идентификатором, добавленную в коллекцию задач
- **AND** соседние задачи и зависимость остаются без изменений

#### Scenario: Отклонение операции над несуществующей задачей

- **GIVEN** план без задачи с идентификатором `t404`
- **WHEN** выполняется изменение даты задачи `t404`
- **THEN** результат — отклонение с кодом `unknown-task` и понятным сообщением
- **AND** содержимое плана остаётся без изменений

#### Scenario: Перевёрнутый интервал отклоняется целиком

- **GIVEN** задача с датами пн 12.10.2026 – пт 16.10.2026
- **WHEN** выполняется ручной ввод дат с окончанием раньше начала
- **THEN** результат — отклонение с кодом `inverted-interval`
- **AND** даты задачи остаются прежними

### Requirement: Очистка ссылок при удалении задачи

Удаление задачи SHALL удалять саму задачу и все зависимости, в которых она участвует как предшественник или последователь. Удаление MUST NOT изменять группы, ресурсы, типы работ, периоды недоступности и другие задачи. Этот контракт SHALL служить образцом очистки ссылок для последующих операций удаления других сущностей плана.

#### Scenario: Удаление задачи из цепочки зависимостей

- **GIVEN** задачи A, B, C с зависимостями A→B и B→C
- **WHEN** удаляется задача B
- **THEN** задачи A и C остаются в плане
- **AND** обе зависимости A→B и B→C удалены

#### Scenario: Справочники не затрагиваются

- **GIVEN** задача с группой, назначенным ресурсом и типом работы
- **WHEN** задача удаляется
- **THEN** группа, ресурс и тип работы остаются в плане
