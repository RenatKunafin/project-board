## Context

MVP-состав закрыт: 19 действующих capabilities, реестр задач Done по всем зависимостям карточки, релиз v1.0.1 опубликован (PBT-059, включая живые проверки обновления/возврата). Отменённые владельцем PBT-062/065/066 и будущие PBT-063/064 не входят в обязательный объём; PBT-092 (превышение бюджета добавления задачи) — Proposed: свежий полный headed-прогон bench:release на кандидате v1.0.1 уложился во все бюджеты (addTask median 285.3 / p95 287.1 при бюджете 400), историческое превышение не воспроизведено.

## Goals / Non-Goals

Goals: доказательная матрица «требование → задача → проверка», пользовательская инструкция, явные ограничения и последствия для данных, итоговый проход по v1.0.1 с рабочим примером.

Non-Goals: изменения кода/спек/релизов, возвращение отменённых задач.

## Decisions

### D1. Матрица готовности

Формат — по одной секции на capability: краткая формулировка каждого требования, задачи-реализаторы (по реестру и истории PR), проверки (файлы e2e/unit, сквозные наборы PBT-057/058/059, живые приёмки). Располагается в `docs/research/PBT-061.md` (отчётный артефакт, не продуктовая документация). Незакрытых блокеров нет; известные ограничения перечислены отдельным списком (PBT-092 Proposed, PBT-064 Proposed, CDN-задержка публикации, минимум ширины окна Гантта 608px).

### D2. Пользовательская инструкция

`docs/user-guide.md` — короткая практическая инструкция: начало (открытие адреса, установка PWA), документы и виджеты, размещение окон (каскад/сетка, разворот), проектный Гантт (задачи/группы/зависимости/жесты/зум/фильтры), ресурсный вид, настройки плана (календарь, справочники), проблемы плана и переходы, цвет задач, файловый обмен (экспорт/импорт собственного формата, импорт OnlineGantt с предпросмотром, экспорт PlantUML), офлайн и обновление приложения. Раздел «Данные и ограничения»: локальное хранение IndexedDB, очистка данных сайта удаляет документы, поддержанные браузеры (Chrome/Chromium-браузеры — по фактическим проверкам PBT-059), форматы файлов, отсутствие серверной синхронизации/бэкапа. Ссылка из README.

### D3. Итоговый проход

Живой проход по опубликованной v1.0.1 (MCP-браузер, постоянный HTTPS) с рабочим примером владельца (эталонный `.gantt` 47 задач): импорт с предпросмотром, базовые сценарии инструкции, офлайн. Результат — в отчёте матрицы; скриншоты в test-results.

### D4. Оформление

Задача проверочная: change с `skip_specs: true`; один PR в develop; после приёмки владельцем — архивация без продуктовых дельт, Done.

## Risks / Trade-offs

Матрица ручная — риск пропуска; смягчение: генерация перечня требований напрямую из `openspec/specs` и сверка количества.

## Migration Plan

Не требуется.

## Test Strategy

Читаемость и полнота матрицы (число требований совпадает с `openspec/specs`), инструкции (проход по ней на живом сайте), отсутствие незакрытых блокеров; OpenSpec strict и действующие наборы зелёные на момент приёмки.
