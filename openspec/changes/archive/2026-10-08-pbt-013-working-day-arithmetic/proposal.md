## Why

Прототипы Гантта (PBT-014/015) и ядро планирования (PBT-030+) считают рабочие дни, лаги и конфликты по календарю плана. Правила зафиксированы [ADR PBT-003](../../docs/adr/PBT-003.md) (планирование по дням, включительное окончание, рабочая длительность по календарю, выходные по умолчанию пн–пт, праздники и рабочие исключения). Нужны чистые переиспользуемые функции дат — без React, IndexedDB и библиотек диаграмм (DoD). Ожидания уже выписаны в фикстурах PBT-012 (E1–E10).

## What Changes

- `packages/gantt/src/working-calendar.ts`: `createWorkingCalendar({ workingDays, holidays, workingExceptions })` → объект с чистыми функциями `isWorkingDay(date)`, `nextWorkingDay(date)`, `addWorkingDays(date, count)`, `workingDaysBetween(start, end)`.
- Даты — строки `YYYY-MM-DD` без времени суток (ADR-003 D-представление); внутренняя арифметика на UTC-полудне, чтобы переходы DST не сдвигали календарную дату.
- Рабочее исключение: отдельный выходной отмечается рабочим (решения 8.2) — приоритет выше праздника и выходного дня недели.
- Валидация календаря при создании: без доступных рабочих дней → `WorkingCalendarError` (конечный, определённый результат вместо бесконечных циклов).
- Unit-тесты: таблица ожиданий E1–E8 из `tests/fixtures/gantt/small-plan-expected.md` (фикстуры PBT-012) + календарные границы (месяц/год, високосный день, DST, однодневный интервал, end < start).
- E9/E10 (циклы зависимостей, отрицательный лаг) — вне этого change: валидация зависимостей появится в PBT-035, границы лага покрываются арифметикой (лаг ≥ 0).

## Capabilities

### New Capabilities

- `working-calendars`: рабочие дни недели, праздники и рабочие исключения календаря плана; следующий рабочий день; прибавление рабочего лага; рабочая длительность включительного интервала; валидация календаря.

## Impact

- `packages/gantt/src/working-calendar.ts` (+ тесты) — первый код модуля Гантта.
- Вход для PBT-014/015 (прототипы используют календарь), PBT-030–036 (ядро), PBT-044 (редактор выходных/праздников).
- Оболочка, SDK и другие пакеты не меняются.
