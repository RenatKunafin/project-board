# PBT-043 — Редактор отпусков

## Why

Периоды недоступности (PBT-034) не имеют UI: создать отпуск нельзя из приложения. Конфликты (PBT-036) и ресурсные дорожки (PBT-047) без отпусков неполны. Отпуск — свойство ресурса, поэтому редактор размещается рядом со справочниками ресурсов.

## What Changes

- Третья секция «Отпуска» в диалоге справочников плана (PBT-041): форма добавления (ресурс-селект, даты начала/окончания), список периодов «ресурс: начало–окончание», инлайн-редактирование (селект + даты в строке), удаление с подтверждением.
- Команды ядра `createUnavailability`/`updateUnavailability`/`deleteUnavailability` через существующий `applyCommand` виджета; ошибки по месту (пустой ресурс, обратный интервал — текст ядра).
- Данные отпусков — отдельный раздел документа (`unavailability`), задачи не затрагиваются.

## Impact

- Изменённые: `packages/gantt/src/ResourceCatalogDialog.tsx` (секция отпусков), `packages/gantt/src/PlanGanttWidget.tsx` (команды недоступностей в switch); e2e `tests/e2e/absences.spec.ts`.
- Ядро не расширяется; delta spec — `resource-planning`.
- Разблокирует: PBT-046 (конфликты с отпусками в UI), PBT-047 (отпуск на дорожке).

## Non-Goals

- Подсветка отпусков на шкале Гантта и дорожках (PBT-046/047).
- Полудневная точность, перенос рабочих дней (исключены решениями).
- Автоматическое перепланирование задач при пересечении с отпуском (ручной режим, §7).
