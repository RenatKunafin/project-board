# PBT-069 — Дизайн-токены и тёмная тема приложения

## Why

Приложение оформлено на временных светлых токенах каркаса PBT-004 (`:root` в `index.css`, системный шрифт). Владелец подготовил интерактивный дизайн-прототип `flexi-dashboard-hub` (секция K реестра) и выбрал его визуальный язык как целевой: тёмная тема на oklch-палитре с трёхуровневыми поверхностями, IBM Plex Sans/JetBrains Mono, тень «плавающих» окон, точечная сетка канваса. README прототипа прямо рекомендует начинать перенос с токенов и рамок окон — это даёт наибольший визуальный эффект при минимальном риске и является базой для PBT-070–075.

Решения владельца (2026-10-19): в этой серии — только тёмная тема (светлая — отдельное решение после серии, карточка PBT-066 уточнена); прогресс задач — вне серии.

## What Changes

- **Единый файл токенов** `apps/project-board/src/tokens.css`: oklch-палитра прототипа (`chrome`/`background`/`surface`/`surface-raised`, `primary`/`success`/`warning`/`destructive`, `muted`/`accent`/`border`/`input`/`popover`, `foreground`), радиусы, `--shadow-float`, токены шрифтов. Подключается первым в `index.css`.
- **Переход всех стилей на новые имена**: `index.css` приложения и css пакетов (`gantt.css`, `resource-timeline.css`, `task-editor.css`, `absence-convert.css`, `onlinegantt-import.css`, `plantuml-export-dialog.css`); литеральные цвета (hex/rgba) переводятся на токены и `color-mix` — остаются только в файле токенов. Спец. токены Гантта/ресурсного вида (выходные, праздники, отсутствие, конфликт) переопределяются производными от семантических.
- **Шрифты локально**: `@fontsource/ibm-plex-sans@5.3.0` (400/500/600/700) и `@fontsource/jetbrains-mono@5.3.0` (400/500) — точные пины, импорт css в приложении; офлайн-требование PWA (PBT-028) соблюдено, внешних CDN-запросов нет.
- **Иконки**: `lucide-react@0.575.0` (точный пин из прототипа) — установка и место-образец: иконки кнопок рамки окна (свёрнуть/развернуть/закрыть) без изменения поведения и aria. Контракт SDK `icon?: string` не расширяется (emoji в каталоге — до отдельного решения).
- **Точечная сетка канваса** (`canvas-grid`, точки 6% белого) — на области каскадного размещения; тайлинг — без точек (RGL-сетка, осознанное отклонение от прототипа, design D6).

## Capabilities

### New Capabilities

- `app-theme`: ADDED — тёмная тема по умолчанию с различимыми уровнями поверхностей; локальные шрифты без внешних запросов; токены — единственный источник цветов.

### Modified Capabilities

(нет — визуальные производные остальных capabilities не меняют наблюдаемого поведения за пределами темы; переоформление компонентов — PBT-070–075)

## Impact

- **Код:** `apps/project-board/src/tokens.css` (новый), `index.css`, `main.tsx` (импорт шрифтов), `packages/dashboard/src/WidgetWindow.tsx` (иконки-образец), css шести файлов `packages/gantt`; `package.json` приложения + lockfile (3 зависимости).
- **Тесты:** e2e на тексты/aria/поведение — без изменений ожидаемо зелёные (цветовых ассертаций нет; проверить grep'ом); полный набор обязателен.
- **Документация:** карточка PBT-069, реестр; ссылка на прототип и референс-скриншоты `screenshots/redesign-ref/`.

## Non-Goals

- Переоформление рамки окна, каркаса, тулбаров и диалогов — PBT-070–075 (здесь только значения токенов и база).
- Светлая тема и переключатель тем — отдельное решение после серии (PBT-066).
- Тёмная тема SVAR (`WillowDark` + `--wx-*` переопределения) — PBT-073; тёмная тема RCT — PBT-074. До них библиотеки отображаются на нейтральных значениях спец. токенов, переведённых на производные семантических (не светлые).
- Наборы иконок для каталога виджетов и расширение SDK-контракта иконок.
- Прогресс задач — вне серии (PBT-067, отдельное будущее решение).
