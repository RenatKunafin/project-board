# PBT-056 — Экспорт PlantUML из интерфейса

## Why

Генератор готов (PBT-055: `serializePlanToPlantUml` — текст в стиле целевого примера + отчёт о непереносимом), но воспользоваться им из приложения нельзя. Задача закрывает ветку обмена файлами: из открытого плана — предпросмотр текста и ограничений, скачивание `.puml` и копирование для вставки в PlantUML-макрос Confluence.

## What Changes

- **Кнопка в тулбаре плана** (📊, aria-label «Экспорт PlantUML», рядом с 📤/📥) — открывает **диалог предпросмотра**.
- **Диалог `PlantUmlExportDialog`:** сгенерированный текст (только чтение, моноширинный блок со скроллом), перечень ограничений из отчёта генератора, краткая инструкция публикации: текст PlantUML самодостаточен; конкретная инсталляция Confluence подключает его своим макросом/плагином — требования инсталляции вне нашего приложения. Кнопки: **«Скопировать»** (буфер обмена с fallback-выделением там, где поддержано), **«Скачать .puml»** (Blob, офлайн), «Закрыть»; Esc — закрыть.
- **Имя файла** `pb-plantuml-YYYY-MM-DD_HH-mm-ss.puml` — по прецеденту `planFileName` (PBT-050).
- **Экспортируется полный план**: фильтры/состояния представления виджета не влияют на содержимое и не изменяются сами; документ и его ревизия не трогаются (чтение).

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `plantuml-export`: ADDED — «Экспорт из интерфейса с предпросмотром»: команда даёт предпросмотр текста и ограничений до скачивания, скачивание по шаблону имени, копирование текста, полный план независимо от фильтров, офлайн, без изменений документа.

## Impact

- **Код:** `packages/gantt` — новый диалог + правки `PlanGanttWidget.tsx` (кнопка, состояние, обработчики); генератор, SDK, платформа не меняются.
- **Тесты:** e2e (экспорт контрольного плана: имя файла, содержимое совпадает с генератором, ограничения видны, фильтр не влияет); unit — `plantumlFileName` при необходимости.
- **CSS:** токены, без хексов.

## Non-Goals

- Рендер PNG/SVG в приложении (получатель рендерит у себя; метод — закрепленный PlantUML-рендер).
- Настройка состава экспорта (профиль один, PBT-055).
- Интеграция с конкретным Confluence (инструкция текстом; требования инсталляции различаются).
- Экспорт из ресурсного вида (тулбар — у проектного Гантта, как PBT-051).
