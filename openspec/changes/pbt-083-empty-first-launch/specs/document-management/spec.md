## ADDED Requirements

### Requirement: Запуск без автоматических демонстрационных документов

Приложение SHALL создавать новые пользовательские документы только по явному действию пользователя, включая создание в каталоге и импорт файла. Запуск, перезапуск и восстановление рабочего пространства MUST NOT создавать демонстрационные документы или пополнять каталог до заданного количества чек-листов. Ранее сохранённые документы SHALL сохраняться независимо от их названий, пустого содержимого и количества открытых окон. Ошибка восстановления SHALL оставаться ошибкой загрузки, а не маскироваться созданными примерами или успешным пустым каталогом.

#### Scenario: Каталог чистого профиля пуст

- **GIVEN** у профиля нет сохранённых документов и восстановление завершилось успешно
- **WHEN** пользователь впервые открывает приложение и каталог документов
- **THEN** каталог показывает отсутствие документов с возможностью создания
- **AND** после перезагрузки без пользовательского создания документов каталог остаётся пустым

#### Scenario: Сохранённый план не дополняется чек-листами

- **GIVEN** сохранён план с открытым окном и в хранилище нет чек-листов
- **WHEN** приложение перезапускается
- **THEN** план и окно восстанавливаются, дополнительные документы и окна не появляются

#### Scenario: Удаление последнего документа не возвращает примеры

- **GIVEN** пользователь удалил последний документ и закрыл его окна
- **WHEN** приложение перезапускается
- **THEN** каталог документов остаётся пустым
- **AND** автоматические чек-листы не создаются

#### Scenario: Документы без сохранённых вкладок остаются в каталоге

- **GIVEN** документы сохранены, но сохранённых вкладок нет
- **WHEN** приложение запускается
- **THEN** существующие документы доступны в каталоге, их содержимое сохранено
- **AND** приложение не создаёт новые документы и не открывает существующие без действия пользователя

#### Scenario: Существующие примеры сохраняются

- **GIVEN** в хранилище есть документы «Список 1» и «Список 2», пустые или отредактированные
- **WHEN** приложение перезапускается после обновления
- **THEN** документы и сохранённые окна остаются доступными без удаления, переименования или очистки

#### Scenario: Ошибка восстановления не создаёт демонстрационные документы

- **GIVEN** восстановление документов завершилось ошибкой
- **WHEN** приложение открывает пространство и пользователь открывает каталог документов
- **THEN** каталог показывает ошибку загрузки
- **AND** приложение не создаёт документы для подмены отсутствующих результатов восстановления
