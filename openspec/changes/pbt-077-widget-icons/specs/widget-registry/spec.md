## ADDED Requirements

### Requirement: Единые иконки встроенных типов виджетов

Платформа SHALL отображать встроенные типы виджетов контурными иконками по прототипу: план — календарь диапазона, ресурсы — группа людей, чек-лист — список задач. Одинаковый тип SHALL иметь одинаковую иконку в рамке окна и местах выбора виджета/представления, поддерживающих графические иконки. Декоративные иконки MUST NOT изменять доступные названия действий. Технические ключи иконок MUST NOT отображаться пользователю вместо названия.

#### Scenario: Иконка типа совпадает в каталоге и рамке

- **GIVEN** пользователь выбирает встроенный тип виджета в каталоге
- **WHEN** виджет добавлен на вкладку
- **THEN** рамка показывает ту же контурную иконку типа, что и каталог
- **AND** название типа и доступные названия действий сохранены

#### Scenario: Выбор типа в нативном списке

- **GIVEN** тип документа выбирается нативным списком, поддерживающим только текст
- **WHEN** пользователь открывает список
- **THEN** видит понятное название типа без технического ключа иконки

### Requirement: Название команды каталога виджетов

Кнопка открытия каталога виджетов в верхней панели SHALL показывать только текст «Виджеты», без иконки и знака «+». Её доступное имя SHALL быть «Виджеты».

#### Scenario: Открытие каталога из верхней панели

- **GIVEN** пользователь находится в рабочем пространстве
- **WHEN** нажимает кнопку «Виджеты» в верхней панели
- **THEN** открывается каталог виджетов
