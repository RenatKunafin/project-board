## ADDED Requirements

### Requirement: Операции над пунктами списка

Модуль чек-листа SHALL предоставлять операции над документом списка: добавление пункта, изменение текста пункта, отметка и снятие выполнения, удаление пункта. Добавление пункта с пустым или состоящим только из пробелов текстом MUST NOT изменять документ. Идентификаторы пунктов SHALL быть уникальны в пределах документа.

#### Scenario: Добавление пункта

- **GIVEN** документ списка с двумя пунктами
- **WHEN** пользователь добавляет пункт с текстом «Купить молоко»
- **THEN** документ содержит три пункта, новый пункт не выполнен и находится в конце списка

#### Scenario: Пустой текст не создаёт пункт

- **GIVEN** документ списка с двумя пунктами
- **WHEN** пользователь пытается добавить пункт с текстом из одних пробелов
- **THEN** документ остаётся с двумя пунктами и редакция документа не изменяется

#### Scenario: Переименование, отметка и удаление

- **GIVEN** документ списка с пунктом «Задача»
- **WHEN** пользователь переименовывает пункт в «Задача обновлена», отмечает выполнение, затем удаляет пункт
- **THEN** после каждого действия документ отражает ровно одно изменение: новый текст, признак выполнения true, отсутствие пункта

### Requirement: Пустое состояние списка

Документ списка без пунктов SHALL отображаться определённым пустым состоянием с подсказкой о добавлении первого пункта.

#### Scenario: Пустой список

- **GIVEN** документ списка не содержит пунктов
- **WHEN** экземпляр виджета отображает документ
- **THEN** пользователь видит пустое состояние с подсказкой, а форма добавления доступна

### Requirement: Согласованность экземпляров одного списка

Экземпляры виджетов, ссылающиеся на один документ списка, SHALL отображать одинаковое содержимое после каждой зафиксированной операции.

#### Scenario: Два экземпляра одного списка

- **GIVEN** два экземпляра виджета открыли один документ списка
- **WHEN** в первом экземпляре добавляется пункт
- **THEN** во втором экземпляре отображается тот же пункт без ручного обновления

### Requirement: Независимость списков

Документы разных списков SHALL быть независимы: операции над одним списком MUST NOT изменять содержимое другого.

#### Scenario: Два разных списка

- **GIVEN** два документа списка с разными пунктами открыты в разных экземплярах
- **WHEN** в первом списке удаляется пункт
- **THEN** второй список остаётся без изменений
