## Why

В Brave 1.95.101 на macOS редактор заметки после последовательного ввода `#`, `#`, пробела показывает только один `#`, хотя значение поля и сохранённый текст содержат `## `. В Safari сбоя нет; он воспроизводится в Brave без расширений и мешает видеть исходный Markdown при редактировании.

## What Changes

- Сохранять точное визуальное отображение исходного текста в редакторе заметки при посимвольном вводе в Brave/Chromium.
- Не менять текст заметки, немедленную запись общего документа, поведение конфликтов и отображение Markdown-предпросмотра.
- Добавить браузерную проверку последовательного ввода одинаковых символов и пробела в редакторе.

### New Capabilities

### Modified Capabilities
- `notes`: текст редактора должен оставаться визуально точным при вводе и обновлениях состояния, включая соседние одинаковые символы и завершающий пробел.

## Impact

Изменения в `packages/notes/src/notes.css` и browser e2e для блокнота. Схема документа, API SDK, формат Markdown и зависимости не меняются.
