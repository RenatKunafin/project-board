# PBT-074 — Ресурсный вид: тёмная тема и легенда

## Why

Платформа, каркас и проектный Гантт уже в тёмной теме по токенам прототипа (PBT-069–073), а ресурсный вид остаётся со светлой нейтральной шапкой RCT, текстовыми строками сайдбара без аватаров, синтетическими зум-кнопками «+/−» и без легенды. Попутно закрывается **регресс PBT-069**: инлайн-стили полос адаптера (`resource-timeline-adapter.ts`) ссылаются на токены `--color-accent`/`--color-on-accent`/`--color-danger`, удалённые при переходе на `tokens.css` (переименование затронуло только CSS-файлы, `.ts`-инлайны проскочили мимо) — с PBT-069 фон полос задач фактически прозрачный, у конфликтных полос нет рамки, у полос недоступности нет цвета текста; юнит-тесты этого не видят (ассертят строки, а не вычисленные значения). Референс: прототип `flexi-dashboard-hub` (`ResourcePrototype.tsx`, `ResourceTimelineChart.tsx`, `styles.css` — блок `.resource-timeline-chart`); скриншот `screenshots/redesign-ref/01-dashboard-overview.png` (нижнее окно). Прототип использует ту же версию RCT `0.30.0-beta.19`, что и проект, — переопределения переносимы напрямую.

## What Changes

- **Токены полос и слоя дней** (`tokens.css`, новые `--color-rt-*`): фон задач (primary 35% + surface), рамка конфликтов (destructive), выходные (muted 60%, полупрозрачно), праздники (warning 12%, полупрозрачно). Полосы адаптера переходят на них — висячие ссылки PBT-069 закрываются: задачи — primary mix + primary-рамка + текст foreground 13px; недоступность — warning 14% + warning-рамка + warning-текст; конфликты — destructive 18% + destructive-рамка. Общие `--color-gantt-*` не трогаются (их использует проектный Гантт).
- **Оформление RCT по прототипу:** шапка шкалы `surface-raised` с primary-строкой месяца `chrome` и mono-подписями дат 12px; сайдбар и строки `surface`; границы на `--border`; линия курсора `primary`.
- **Сайдбар с аватарами:** `groupRenderer` — кружок 24px `secondary` с инициалами ресурса + имя с обрезкой; заголовок сайдбара «Исполнитель» (`SidebarHeader`).
- **Шапки шкалы:** `TimelineHeaders` (primaryHeader «месяц год» 28px + вторичная дневная 28px) вместо дефолтных шапок RCT.
- **Плотность:** высота дорожки 34 → **42px**, `itemHeightRatio` 0.7 (решение владельца 2026-10-21 — как в прототипе).
- **Легенда + футер** (решение владельца 2026-10-21): строка легенды — свотчи «Задачи / Отсутствия / Конфликты» + mono-диапазон видимой области справа; ниже — 24px-строка с названием документа (единый паттерн PBT-073). Диапазон — производное отображения, записей не создаёт.
- **Тулбар в стиле прототипа:** поиск с иконкой внутри поля (растягивается), селект ресурса, зум-кнопки ghost с ZoomIn/ZoomOut (lucide уже запинен в `packages/gantt` с PBT-073). Все `data-rt-*`-локаторы e2e сохраняются.
- Жесты drag/resize (PBT-048), контракт адаптера, ядро — без изменений.

### Modified Capabilities

- `resource-timeline`: ADDED «Тёмная тема, аватары и легенда ресурсного вида». Примечание: карточка указывала модификацию capability; по существу ни одно действующее требование не меняет поведения (даты, жесты, фильтры, зум — нетронуты), поэтому дельта оформлена добавлением нового требования (прецедент: PBT-073 — ADDED-требования внутри изменяемой capability).

## Impact

- **Код:** `packages/gantt/src/ResourceTimelineWidget.tsx` (groupRenderer, TimelineHeaders, тулбар, легенда, футер, lineHeight), `resource-timeline.css` (шапка/границы/слой дней/тулбар/легенда/футер), `resource-timeline-adapter.ts` (только стилевые константы полос — значения токенов), `apps/project-board/src/tokens.css` (4 новых rt-токена).
- **Тесты:** unit `resource-timeline-adapter.test.ts` — ассерты имён токенов; e2e `resource-timeline.spec.ts` — обновление ассертов сайдбара (аватары меняют текст строк), новые проверки легенды/аватара; жестовые спеки `resource-timeline-editing.spec.ts` — регресс без правок семантики.
- **Скриншоты до/после:** обзор вида, конфликтный план; 1024×778 и широкое окно.

## Non-Goals

- Прогресс-слой полос (решение владельца 2026-10-19 — вне серии).
- Строка демо-статуса «Демонстрационный план» из прототипа (демо-логика, не переносим — принцип серии); `role="status"` в футере ресурсного вида не вводим: действий, порождающих статусы, здесь нет.
- Жесты, семантика дат, контракт адаптера, ядро плана — без изменений.
- Ресайз-контролы каскада, тулбар-строка 2 и зум-семантика проектного Гантта — PBT-076.
- Светлая тема — PBT-066 (после серии).
