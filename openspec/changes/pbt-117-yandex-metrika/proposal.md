## Why

Опубликованному Project Board нужна аналитика посещений, чтобы видеть охват публичного PWA и качество первого открытия. Владелец предоставил счётчик Яндекс Метрики `113967203` и подтвердил временное включение Вебвизора с последующим отключением.

## What Changes

- Подключить Яндекс Метрику только к публичной сборке GitHub Pages, с одним просмотром при открытии SPA.
- Использовать счётчик `113967203` с временной конфигурацией `webvisor: true`, `clickmap: true`, `trackLinks: true`, `ecommerce: "dataLayer"` и стандартными параметрами просмотра.
- Сделать включение управляемым build-флагом, чтобы Вебвизор и весь счётчик можно было отключить без изменения кода.
- Не отправлять цели, пользовательские события, названия/содержимое документов, поисковые строки или локальные идентификаторы; `dataLayer` не заполнять.
- Исключить реальные запросы Метрики из dev, локального preview, тестов и обычной production-сборки без release-флага.
- Проверить SPA/PWA, подпуть `/project-board/`, offline, блокировку сети и отсутствие дублей при переключении вкладок и окон.

## Capabilities

### New Capabilities

- `visit-analytics`: безопасное подключение аналитики посещений к опубликованной SPA-сборке.

### Modified Capabilities

Нет.

## Impact

- `apps/project-board/src/main.tsx` и новый небольшой адаптер/конфигурация аналитики.
- `apps/project-board/vite.config.ts` или workflow публикации для release-only build-флага.
- production browser/PWA проверки и документация релизной настройки.
- Вебвизор временно расширяет собираемые данные до записи отображённого HTML и действий пользователя; это осознанное решение владельца для текущего этапа и должно быть отключено последующим переключением флага.
