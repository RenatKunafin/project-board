## ADDED Requirements

### Requirement: Создание документа модулем во время работы

Модуль SHALL иметь возможность создавать документы через сервис документов во время работы приложения, передавая владеющий модуль, тип документа, версию схемы, название и содержимое. Созданный модулем документ SHALL появляться в каталоге документов без перезапуска приложения, сохраняться по общим правилам автосохранения и восстанавливаться при следующем старте. Каталог MUST NOT интерпретировать содержимое созданного документа.

#### Scenario: Импортированный модулем документ виден в каталоге

- **GIVEN** модуль плана создал документ через сервис во время работы приложения (импорт файла)
- **WHEN** пользователь открывает каталог документов
- **THEN** каталог содержит созданный документ с переданным названием и типом

#### Scenario: Созданный модулем документ восстанавливается после перезапуска

- **GIVEN** документ, созданный модулем через сервис, сохранён хранилищем
- **WHEN** приложение перезапускается
- **THEN** документ восстанавливается с теми же названием, типом и содержимым и открывается в зарегистрированных представлениях
