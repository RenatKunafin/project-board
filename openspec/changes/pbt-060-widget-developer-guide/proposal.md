## Why

Перед релизом разработчику нужен воспроизводимый способ добавить виджет, а репозиторию — актуальная структура без завершённых стендов, одноразовых скриптов и дублируемой истории. Владелец 2026-10-24 расширил PBT-060 уборкой и переименованием `.docs` в `docs`. Конкретные находки и границы — audit.md.

## What Changes

- Руководство `docs/widget-development.md` по фактическому SDK с небольшим примером, двумя видами общего документа и независимыми настройками; проверка подключения с чистого checkout.
- Переименование `.docs/` → `docs/` с исправлением рабочих ссылок, включая архивные Markdown и локальные инструкции.
- Удаление `apps/load-demo` после завершённой PBT-058 (ADR-6 PBT-017), его npm-команд/ссылок и workspace-записей lockfile.
- Удаление архивных скриншотов и одноразового `__shot.cjs`; новые UI-артефакты — в test-results, отчёт о проверке — в PR. Исправление e2e, пишущего в архив.
- Компактные AGENTS.md и README без журнала стадий; тематические правила проекта — .agents/rules/*.md с явными ссылками из AGENTS.md. Исправление устаревшего OpenSpec-конфига и дубликатов .gitignore.
- Удаление неподключённого глобального реестра SVAR API после повторной проверки потребителей; сохранение используемой тестовой диагностики.
- Общие правила для разных агентов и минимальные конфиги загрузки; одобренный вариант — `.agents/rules` и `.agents/skills`, тонкие адаптеры (agent-options.md). Нужные интеграции OpenSpec сохраняются.

## Capabilities

Новых продуктовых требований нет: `skip_specs: true`. Публичный SDK описывается и проверяется примером, семантика существующих виджетов не меняется.

## Impact

Документация, правила агента, пример виджета, отработавший load-demo, тестовые пути артефактов, npm scripts/lockfile и неиспользуемая диагностика. Измеряемый список удаляемых файлов и ссылки проверяются перед удалением. Git-история не переписывается.

## Non-goals

Обновление версий библиотек, рефакторинг Гантта/платформы, смена SDK/БД/форматов, публикация PBT-059, переписывание ADR и всего архива OpenSpec, удаление фикстур/production-иконок/шрифтов, отказ от живой проверки UI. Настройка глобальных разрешений команд Codex в эту задачу не входит.
