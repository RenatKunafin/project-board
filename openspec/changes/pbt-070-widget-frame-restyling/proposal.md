# PBT-070 — Рамка окна в стиле прототипа

## Why

Токены и тёмная тема внедрены (PBT-069), но рамка окна сохранила компоновку каркаса PBT-020: авто-высота заголовка, текстовые символы кнопок (частично заменены иконками в PBT-069), 12px полужирный заголовок, бордер-уголок resize и отсутствие переходов. README прототипа `flexi-dashboard-hub` рекомендует порядок «сначала токены и рамки окон» — рамка даёт второй по величине визуальный эффект серии. Референс: `WidgetFrame.tsx` прототипа, скриншоты `screenshots/redesign-ref/02-widget-maximized.png`, `13-collapsed-widget.png`.

## What Changes

- **Заголовок 32px** (фикс): слева иконка типа виджета (emoji — до отдельного решения о наборе иконок) и иконка-ручка переноса `GripVertical` (lucide, приглушённая); название 14px обычного веса с обрезкой; фон — полупрозрачная приподнятая поверхность (`surface-raised`/40) с нижней границей.
- **Кнопки 24×24** ghost-стиля: сворачивание/разворачивание (ChevronUp/ChevronDown — с PBT-069) и закрытие (X) с hover; закрытие — hover акцентом `destructive`. Подписи aria и поведение не меняются.
- **Resize-уголок каскада** в стиле прототипа (двойной диагональный штрих, цвет токеном) вместо одиночного бордер-уголка; ручки остальных сторон — без визуальных изменений.
- **Переходы рамки** — только `box-shadow`/`border-color` (как в прототипе): активация/деактивация без скачков геометрии.
- Типографика заголовка: 14px (`text-sm` прототипа), обычный вес, `foreground`/90.

### Modified Capabilities

## Impact

- **Код:** `packages/dashboard/src/WidgetWindow.tsx` (grip-иконка), `apps/project-board/src/index.css` (правила `widget-window__*`, `cascade-resize-se`); `lucide-react@0.575.0` уже в пакете (PBT-069).
- **Тесты:** e2e `widget-windows` кликают по aria-label — без изменений; визуальная проверка скриншотами до/после; полный набор.
- **Реестр:** секция K, PBT-070.

## Non-Goals

- Разворачивание окна на весь дашборд — PBT-071 (кнопка появится там).
- Переименование окна двойным кликом из прототипа — не переносится (название окна = имя документа, решение PBT-025; зафиксировано в секции K реестра).
- Цветовая точка-индикатор warning из прототипа — не переносится: слева уже занимает место иконка типа виджета, точка — декор без данных (design D1).
- Resize-ручка сетки RGL (тайлинг) — без изменений: CSS-переопределение хэндла RGL рассинхронизирует жесты (прецедент PBT-068 про `cellHeight`).
- Переоформление тулбаров виджетов, топ-бара и панелей — PBT-072–075.
