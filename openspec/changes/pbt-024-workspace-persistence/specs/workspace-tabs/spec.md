## ADDED Requirements

### Requirement: Восстановление вкладок при старте

При запуске приложения платформа SHALL восстанавливать вкладки из локального хранилища: порядок, названия, активную вкладку и режим размещения каждой вкладки. Если сохранённых вкладок нет, приложение SHALL начать с исходного состояния. Восстановление MUST NOT пересоздавать документы.

#### Scenario: Перезапуск восстанавливает вкладки

- **GIVEN** приложение с вкладками «Чек-листы» (активная) и «План ОКАД» (каскад) закрыто и открыто заново
- **WHEN** рабочее пространство восстанавливается
- **THEN** вкладки в прежнем порядке с прежними названиями, активна «Чек-листы», «План ОКАД» — в режиме каскада

#### Scenario: Первый запуск начинает с исходного состояния

- **GIVEN** локальное хранилище не содержит сохранённых вкладок
- **WHEN** приложение запускается впервые
- **THEN** открывается исходное пространство, вкладки можно создавать как обычно
