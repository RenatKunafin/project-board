# PBT-037 — Проектный Гантт из документа плана

## Why

Заглушка виджета «План» (PBT-030) не показывает ничего, кроме названия, — ядро планирования завершено (PBT-030–036), но пользователь по-прежнему не видит план. ADR PBT-017 выбрал SVAR React Gantt 2.8.0 для проектного вида и зафиксировал границы адаптера (ADR-4) и стратегию жестов (ADR-5); спайк PBT-014 подтвердил пригодность. Задача превращает заглушку в продуктовое представление: задачи, дерево групп, сводные полосы, включительные даты, рабочая длительность, подсветка нерабочих дней. Операции редактирования (форма — PBT-038, drag — PBT-039) приходят следующими карточками; здесь представление только читает документ.

## What Changes

- В `packages/gantt` появляется production-адаптер `svar-adapter.ts` (пишется с нуля по схемам отчёта PBT-014, спайковый код не переносится): `planToGanttTasks(plan)` — группы → `type: "summary"` с `parent` (произвольная вложенность), задачи → включительное окончание конвертируется в исключительное (+1 день), FS → `type: "e2s"` с лагом из документа.
- Чистая функция `nonWorkingDayKind(plan, date)` → `'weekend' | 'holiday' | undefined` для подсветки `highlightTime` (по календарю плана: выходные дни недели, праздники, рабочие исключения).
- Новый компонент `PlanGanttWidget` заменяет `PlanPlaceholderWidget` в регистрации модуля: подписка на документ через SDK (паттерн чек-листа), parse с диагностикой при повреждении, SVAR `Gantt` + `Willow` с `inclusiveEnd: true`.
- Представление read-only: жесты перетаскивания блокируются перехватом (`drag-task` → false, с защитой от двойного init StrictMode), форма `Editor` не подключается — документ не меняется при простом отображении (DoD-5); полный механизм ADR-5 (сверка стора после mouseup) — в PBT-038/039.
- Рабочая длительность показывается собственным вычислением ядра (PBT-013) вместо календарной колонки SVAR (по образцу спайка).
- При `visible: false` тяжёлый рендер SVAR не монтируется, подписка на документ сохраняется (контракт PBT-027).
- Зависимость `@svar-ui/react-gantt@2.8.0` (точный пин, MIT) — в `packages/gantt`; SVAR-типы не протекают за пределы пакета.
- Delta spec: новая capability `project-gantt`.

## Capabilities

### New Capabilities

- `project-gantt` — проектное представление документа плана: чтение через адаптер, включительные даты, рабочая длительность, подсветка нерабочих дней, общий документ для нескольких экземпляров.

### Modified Capabilities

- Нет (изменение компонента зарегистрированного типа — внутри модуля; поведение каталога не меняется).

## Non-goals

- Редактирование из Гантта: форма задач (PBT-038), drag/resize полос (PBT-039) — здесь блокируются.
- Управление группами в дереве (PBT-040): сворачивание/разворачивание групп — да (B4, состояние виджета), перенос/создание — нет.
- Редакторы ресурсов, зависимостей, конфликтов в UI (PBT-041–046).
- Ресурсное представление (PBT-047+), фильтры и настройки представлений (PBT-049).
- Миграции формата, изменения платформы и SDK.

## Impact

- Новые файлы: `packages/gantt/src/svar-adapter.ts`, `packages/gantt/src/svar-adapter.test.ts`, `packages/gantt/src/PlanGanttWidget.tsx`, `packages/gantt/src/gantt.css` (только var()-токены), e2e `tests/e2e/plan-gantt.spec.ts`.
- Изменённые: `packages/gantt/src/index.ts` (экспорт, замена заглушки), `packages/gantt/package.json` (+`@svar-ui/react-gantt@2.8.0`), контрольный фикстурный файл переносится в тесты пакета; заглушка `PlanPlaceholderWidget` удаляется.
- `tests/fixtures/gantt/small-plan.json` (PBT-012) — golden-источник unit-тестов адаптера (перенос стал тривиальным — design D1 PBT-030).
- Разблокирует: PBT-038 (форма поверх этого представления), PBT-039 (drag по стратегии ADR-5), PBT-040 (дерево групп).
