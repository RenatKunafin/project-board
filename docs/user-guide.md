# Project Board — руководство пользователя

Project Board — офлайн-дашборд для планирования: общие документы, вкладки, виджеты, проектный Гантт и ресурсный график. Работает в браузере; данные хранятся локально на вашем устройстве.

Адрес приложения: **https://renatkunafin.github.io/project-board/**

## Начало работы

Откройте адрес в браузере (Chrome или другой Chromium-браузер). Первый запуск показывает пустой дашборд с подсказкой — добавьте первый виджет кнопкой «Добавить виджет на вкладку».

**Установка приложением** (PWA): значок «Установить» в адресной строке браузера → приложение запускается отдельным окном без адресной строки. Установленный вариант работает и без интернета.

**Офлайн**: всё приложение заранее сохраняется на устройство. Отсутствие сети не мешает работе; статус «Готово к работе офлайн» виден вверху. После появления новой версии приложение предложит обновиться — по кнопке «Обновить» оно перезапустится на новую версию, документы и расположение окон сохранятся.

## Рабочее пространство

- **Вкладки** сверху — несколько независимых рабочих столов; «+» добавляет новую, крестик закрывает (окна вкладки закрываются, документы остаются).
- **Виджеты** (справа вверху) — каталог доступных видов; «Документы» — каталог всех ваших документов: открыть, переименовать, создать, удалить (удаление спрашивает подтверждение и предупреждает о закрытых окнах).
- **Размещение окон**: «Каскад» — свободное расположение с перетаскиванием за заголовок и изменением размера за края; «Сетка» — выравнивание по клеткам. Кнопка в заголовке окна разворачивает его на весь дашборд.
- Закрытие окна (крестик) не удаляет документ — снова откройте его через «Документы» или «Виджеты».

## Документы и два вида плана

Один план можно открыть в двух видах одновременно — они показывают одно и то же содержание и обновляются друг за другом.

### Проектный Гантт

Дерево задач и групп слева, диаграмма справа. Сверху — частые действия: «Задача», «Группа», настройки плана (⚙), меню «⋯» (импорт/экспорт файлов, экспорт PlantUML) и счётчик проблем; ниже — поиск по названию, фильтр по исполнителю, масштаб «Дни/Недели».

- **Задача**: название, даты (длительность в рабочих днях, окончание включительное), группа, исполнители, типы работ, предшественники (FS-связи с лагом) и цвет.
- **Жесты**: перетаскивание полосы переносит задачу, за края — меняет длительность (рабочая длительность сохраняется).
- **Цвет задачи**: в форме или правым кликом по полосе — палитра из 10 цветов и «Авто». Цвет — часть плана: сохраняется, переносится в файлы и публикацию.
- **Связи**: линия «окончание → начало»; нарушения (задача раньше предшественника) попадают в проблемы.

### Ресурсный вид

Дорожки исполнителей с их задачами и отсутствиями; пересекающиеся несовместимые работы выделяются как конфликты. Задачи можно выделять и переносить/растягивать жестами; двойной клик открывает форму задачи.

## Календарь и справочники (Настройки плана)

Разделы: исполнители, типы работ (с признаком параллельности), отсутствия, календарь (рабочие дни недели, праздники, рабочие исключения). Изменения календаря не двигают сроки задач — меняется их рабочая длительность; подсветка нерабочих дней на диаграмме следует календарю.

## Проблемы плана

Кнопка «Проблемы (N)» — список нарушений FS, конфликтов несовместимых работ и пересечений с отсутствиями: группы, фильтры, поиск по задаче/исполнителю. «Показать» раскрывает и показывает задачу на диаграмме, «Открыть» — форму редактирования.

## Файлы: обмен и публикация (меню «⋯»)

- **Экспорт плана** — файл собственного формата (`pb-plan-…json`) со всем содержимым.
- **Импорт плана** — файлы собственного формата и OnlineGantt `.gantt`; импорт создаёт новый независимый документ, `.gantt` сначала показывает предпросмотр (сводка, предупреждения, неназначенные строки).
- **Экспорт PlantUML** — текст диаграммы Ганта для публикации (например, в Confluence): предпросмотр, ограничения, скачивание `.puml` и копирование. Цвет задач переносится в публикацию.

## Данные и ограничения

- **Где хранятся данные**: только локально, в браузере (IndexedDB). Сервера и синхронизации между устройствами нет.
- **Очистка данных сайта** (или удаление приложения) **удаляет все документы безвозвратно** — заранее делайте экспорт нужных планов.
- **Браузеры**: проверены Chrome/Chromium (установка PWA, офлайн, обновление). В остальных современных браузерах основные функции работают, установка — по поддержке браузера.
- **Форматы**: собственный `.json`, импорт OnlineGantt `.gantt` (часть полей — прогресс и т.п. — не переносится, отчёт покажет что именно), публикация PlantUML `.puml`.
- **Новое окно того же плана** — ещё одно представление: изменения видны сразу во всех окнах.

## Частые вопросы

- **Обновилось что-то неожиданное?** Приложение предлагает обновление при выходе новой версии; до подтверждения работает прежняя.
- **Пропали окна после перезагрузки?** Восстанавливается последнее рабочее пространство; если вкладка была закрыта — откройте документ из каталога «Документы».
- **Как вернуться к старой версии?** Отдельные выпуски может публиковать владелец; возврат проходит тем же управляемым обновлением и не затрагивает ваши данные.
