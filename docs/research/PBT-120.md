## Ответы анкеты (обезличенные)

1. **ОС клиента:** macOS, та же машина, что используется для разработки (строка 2).
2. **Браузер/режим дашборда:** Chrome, обычная вкладка; публичный HTTPS-сайт (строки 5–6).
3. **Конфигурация MCP:** модель `npx`-запуска используется клиентом (Playwright MCP); выбрана для нашего компонента (строки 3–4). Точные поля конфигурации — при пробе 121.
4. **Скилл/инструкции:** не выяснено (строка 10) — работа инструкций не входит в доказательство стенда 121.
5. **Цикл/ожидание:** не выяснено (строка 11); достаточно ручного запуска (строка 8).
6. **Источник:** чтение выбранной доски агенту доступно (строка 7) — допуск к планированию PBT-130 получен.
7. **Ограничения компании:** не сообщены; отмечены неизвестными (строка 12).

## Согласованный протокол пробы PBT-121

Зафиксирован в design (приложение C): установка синтетического MCP-сервера через `npx` на macOS → добавление в клиент по фактической конфигурации (наблюдение B-1 по ходу) → публичный сайт в Chrome (вкладка) → сопряжение → «Обновить» синтетического запроса → обработка агентом по команде → сохранение результата → обезличенный ответ по шагам (сработало/не сработало, текст ошибки без токенов, браузер, режим). Успех — один полный синтетический обмен без отключения защиты браузера.

## Ограничения

- Обмен «запрос → агент → результат → сохранение» в этой задаче не выполнялся и не считается доказанным; доказательство — проба PBT-121.
- Наблюдения приложения B (поля конфигурации, имена инструментов, таймауты) не собраны; соответствующие строки — `неизвестно`.
- Ответы владельца зафиксированы как сообщённые факты о его среде; их поведение не воспроизводилось автоматически.
- Корпоративные данные, названия клиента/компании/систем, токены и внутренние URL в отчёт не входят.
