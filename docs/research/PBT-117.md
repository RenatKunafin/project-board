# PBT-117 — Яндекс Метрика для посещений опубликованного PWA

## Release checklist

- [x] Счётчик `113967203` включается только в шаге GitHub Pages release через `VITE_YANDEX_METRIKA_ENABLED=true`.
- [x] На текущем этапе Вебвизор включён явно через `VITE_YANDEX_METRIKA_WEBVISOR=true`.
- [x] Dev, локальный preview, CI и browser-проверки не отправляют реальные визиты; Pages e2e перехватывает `mc.yandex.ru`.
- [x] В URL Метрики не передаются query/hash; отдельные цели, пользовательские события и `dataLayer` приложения не добавляются. Вебвизор временно остаётся исключением и может записывать отображённый HTML/действия.
- [ ] Перед публикацией владелец проверяет опубликованное уведомление/политику обработки данных.
- [ ] После публикации владелец проверяет один сетевой hit и тестовый визит на реальном Pages URL.

## Локальные проверки

`npm run test:analytics` собирает enabled-вариант, перехватывает запросы к Метрике и проверяет один initial `tag.js`, конфигурацию Вебвизора, offline и отсутствие `dataLayer`. Обычный `npm run build` проверяется отдельным browser-сценарием без release-флага. Pages e2e проверяет enabled-артефакт под `/project-board/`, PWA и offline; внешние запросы перехватываются.

## Отключение Вебвизора

Для следующего release оставить `VITE_YANDEX_METRIKA_ENABLED=true`, выставить `VITE_YANDEX_METRIKA_WEBVISOR=false` в шаге Pages workflow и опубликовать новую сборку. Для полного отключения счётчика выставляется `VITE_YANDEX_METRIKA_ENABLED=false` или переменная удаляется.
