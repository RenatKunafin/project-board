Gate принимает annotated tag на предке main, отклоняет коммит вне main, несовпадение SHA события и тега, push/created/draft и отсутствие истории main. Deployment job зависит от успешного build. Реальный отказ GitHub deployment до первого разрешённого Release не проверялся.

Pages-тест открывает настоящую продуктовую сборку, проверяет HTTP-доступность всех файлов, обработанный Chrome manifest, scope SW, precache, сохранение документа/пространства и повторное открытие офлайн с отключённым HTTP-кэшем. Другая проверка выполняет A→B→A с подтверждением обновления, сохранением документа и настроек окна. Сервер удаляет прежние assets сразу при переключении; старая подготовленная сессия продолжает использовать свой precache. A/B отличаются тестовым JS-probe и не заменяют продуктовые виджеты.

Проверка артефакта отклоняет обычную root-сборку, тестовую сборку с probe и manifest с неверным id. Сырые отчёты Pages находятся в `test-results/pages-results.json`, диагностические копии — в локальной `.context/diagnostics/pbt-059/`.

## Настоящая установка и живая проверка

Chrome 155.0.8059.86, отдельный временный профиль: установка с `http://localhost:4173/project-board/`, standalone-окно и повторный запуск без сети прошли. Installability errors — 0. Обработанные id/startUrl/scope равны `http://localhost:4173/project-board/`. Отчёт и снимок — `test-results/screenshots/pwa-installation.json` и `pwa-installed-chrome.png`.

Именно установка обнаружила ошибку исходного `id: './'`: Chrome разрешает id относительно origin, поэтому для подпути получался ID корня сайта. Исправление задаёт manifest.id по окончательному Vite base. Root-идентичность сохраняется, Pages получает `/project-board/`. Автотест проверяет обработанный браузером ID.

В живом MCP-браузере на отдельном origin `http://127.0.0.1:4188/project-board/` открыты каталог и новый план; чарт отрисован, шрифты загружены, ресурсы остаются в подпути. Ошибок консоли — 0; 4 прежних предупреждения SVAR `Writable _progressLinePoints is not defined`. Отдельный порт исключает перехват сборки старым root Service Worker из предыдущих локальных проверок. Dev возвращён на 5173.
