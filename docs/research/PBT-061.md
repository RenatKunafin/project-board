## Известные ограничения (не блокеры MVP)

- PBT-092 (Proposed): историческое превышение бюджета добавления задачи 400 мс; полный headed-прогон на кандидате v1.0.1 уложился во все бюджеты (median 285.3 / p95 287.1); приоритет за владельцем.
- PBT-064 (Proposed): формат резервной копии — будущая дополнительная возможность.
- Минимальная ширина окна Гантта — 608 px (каскад-снап платформы, PBT-076).
- CDN GitHub Pages: появление новой версии может задерживаться на минуты (живая приёмка: ~5 мин для sw.js); приложение показывает предложение обновления.
- Серверной синхронизации и резервного копирования нет: данные только в IndexedDB браузера (см. инструкцию).

Итого требований: 207. Незакрытых блокеров MVP нет.
