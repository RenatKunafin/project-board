# ADR PBT-101 — Модель блокнота и разрешение конфликтов текста

- **Дата:** 2026-10-28
- **Статус:** Принято владельцем
- **Затрагивает:** PBT-101–PBT-105
- **Источник деталей:** `openspec/changes/pbt-101-notes-document-model/design.md`

## Контекст

Заметки редактируются в нескольких окнах одного общего документа. Автоматическая замена локального ввода внешним сохранением может безвозвратно потерять текст; схема также должна оставаться переносимой через общий бекап.

## Решения

1. Блокнот хранится как `{ notes: [...] }` в содержимом обычного документа `notes`; версия определяется `schemaVersion` оболочки. Название блокнота принадлежит документу, заголовок и исходный Markdown — заметке. Новый блокнот пуст.
2. При внешнем изменении чистый редактор принимает актуальную версию. Если локальный текст изменён, он остаётся черновиком окна и показывается конфликт. Пользователь явно принимает сохранённую версию либо создаёт отдельную заметку из черновика; автоматического слияния нет.
3. Конфликтный черновик нельзя молча отбросить при переключении или закрытии. До разрешения он существует только в памяти окна; долговременное хранение черновиков не входит в PBT-101.
4. Удаление заметки выполняется только после подтверждения вызывающего интерфейса. Корзины и восстановления нет.

## Последствия

Схема заметок переносится в общем бекапе вместе с обычным документом. Пользователь сам выбирает, какой вариант сохранить при конфликте. Если окно закрывается до разрешения, черновик может быть потерян, поэтому интерфейс обязан запросить явный выбор и обозначить это ограничение.
