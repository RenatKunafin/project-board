# Общие инструкции агентов

Проект использует один поддерживаемый источник:

- [AGENTS.md](../AGENTS.md) — обнаруживаемая точка входа и критические ограничения.
- [.agents/rules](../.agents/rules) — процесс, код и проверки; файлы нужно прочитать, если инструмент ещё не загрузил их.
- [.agents/skills](../.agents/skills) — проектные OpenSpec-сценарии в формате SKILL.md.
- docs/ — технические знания и руководства. Локальная .context/ не распространяется через git.

## Подключения

| Инструмент | Правила | Скиллы |
| --- | --- | --- |
| Codex | Корневой AGENTS.md задаёт обязательное чтение общих rules | Нативно .agents/skills |
| OpenCode | AGENTS.md и instructions из opencode.json | Нативно .agents/skills; opsx-команды в .opencode/commands — aliases |
| Claude Code | CLAUDE.md импортирует AGENTS и общие rules, включая совместимость со старыми установками | Относительные симлинки отдельных каталогов .claude/skills на .agents/skills |
| Cursor | Нативный AGENTS.md и его инструкции чтения | Нативно .agents/skills |
| Antigravity | AGENTS.md; общие rules имеют trigger:always_on | Обнаружение проверить на используемой версии |

Правила не копируются в отдельные редакторские наборы. Симлинки скиллов должны разрешаться внутри checkout; при платформе без поддержки симлинков потребуется адаптер, а не независимо редактируемый дубликат. OpenSpec update может перегенерировать интеграции: после него проверить, что проектный workflow остался единым.

Статическая проверка `npm run verify:repository` проверяет пути, имена, общий источник и симлинки. Она не является запуском каждой модели: после подключения агента попросите его перечислить прочитанные правила и доступные openspec-скиллы. Конкретные выполненные проверки указываются в отчёте PR.

## Правила и навыки

В rules находятся постоянные требования. Скилл — сценарий, который загружается для соответствующей задачи, например openspec-propose или openspec-apply-change. Технические детали CLI берутся из установленного OpenSpec; авторизация владельца и правила проекта не подменяются рекомендациями скилла.

Личные навыки, память, MCP, ключи и разрешения исполнения команд остаются в настройках конкретного инструмента. Проектные Markdown-файлы сами по себе не выдают прав на shell или внешние действия.

Формат скилла: [Agent Skills](https://agentskills.io/specification). Механизмы загрузки: [Codex](https://learn.chatgpt.com/docs/build-skills), [OpenCode](https://opencode.ai/docs/skills/), [Claude Code](https://code.claude.com/docs/en/skills), [Cursor](https://cursor.com/docs/skills), [Antigravity](https://www.antigravity.google/docs/rules/). Единого обязательного формата всей папки .agents нет; совместимость проверяется для используемых версий.
