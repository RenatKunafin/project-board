# Глоссарий

- **Блокнот** — общий документ типа «Заметки», который может содержать несколько заметок. Его название не является заголовком какой-либо заметки.
- **Заметка** — отдельный элемент блокнота с заголовком и содержимым; изменение одной заметки не должно менять остальные.
- **Черновик заметки** — текст, введённый в окне, но ещё не сохранённый в общем документе.
- **Конфликт текста заметки** — ситуация, когда общий документ изменился для той же заметки после начала локального редактирования. Локальный текст и сохранённый вариант требуют явного выбора пользователя.
