# Проверки и артефакты

- Перед PR: npm run verify:repository, npm run lint, npm run typecheck, npm test, npm run build, npm run test:browser, openspec validate --all --strict. Проверки запускать по изменённой области и обязательному набору; повторять зелёный набор при новых изменениях или нерешённой проблеме.
- Browser e2e используют production preview: build обязателен перед тестами. Старый preview на4173 и reuseExistingServer могут скрыть устаревшую сборку. Проверить/остановить свои старые процессы и освободить порт; не завершать чужие процессы вслепую.
- Не запускать browser/benchmark одновременно с dev-сервером или живой MCP-сессией. После автоматических проверок вернуть ранее запрошенный dev на5173. После npm ci/изменения зависимостей перезапустить Vite.
- Новый пользовательский сценарий проверять e2e, доменные правила — unit. Проверять фактический результат, видимость и сохранение, а не только наличие DOM/вызов метода.
- Красный тест: проверить чистоту среды, воспроизвести и найти причину. Не добавлять retry/skip ради зелёного результата. Не объявлять обход дефекта его исправлением.
- UI дополнительно проверять живым браузером с реальными событиями и консолью. Снимки/trace/логи — test-results/ или вложения PR; в openspec не добавлять изображения и не записывать туда результаты тестов.
- npm run verify:widget-example проверяет подключение учебного модуля в отдельном чистом worktree текущего коммита; исходное приложение не меняет комплектацию.
- PWA: npm run test:pwa-updates; сквозное планирование: npm run test:planning; производительность: npm run bench:release. Их условия/область — docs/pwa.md и отчёты PBT-057/058. Прогон benchmark должен быть последовательным, headed на согласованном устройстве, без профилировщика; бюджеты не менять ради pass.
- Перед повтором сохранять нужные локальные артефакты: browser-набор может очищать test-results. Исторические численные raw в архиве не перезаписывать.
- В PR указывать фактически выполненные проверки и ограничения. Наличие артефактов/валидный OpenSpec не заменяют тесты; статический разбор конфигов не выдавать за запуск агента.
