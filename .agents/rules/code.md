# Код и архитектура

- React18 + TypeScript + Vite, npm workspaces. apps/project-board — сборка приложения; packages/dashboard — платформа; packages/widget-sdk — публичный контракт; gantt/checklist — предметные модули.
- Платформа не импортирует предметные модули, SDK не зависит от пакетов проекта. Регистрация виджетов — apps/project-board/src/widgets.ts. Доступ к IndexedDB/Dexie — только через адаптер платформы; виджеты используют DocumentService SDK.
- Содержимое документа и настройки окна разделены. Общие данные изменять с актуальной revision; настройки экземпляра сохранять updateSettings. Подписки освобождать при размонтировании, сохранять при hidden; тяжёлую работу приостанавливать по visible.
- Данные и доменные операции неизменяемые. Невалидные данные дают диагностику, а не молчаливый сброс. Миграции — чистые преобразования; будущая версия документа не перезаписывается.
- Новые библиотеки требуют точного пина и изоляции за адаптером. Не обновлять зависимости попутно.
- Цвета — семантические токены приложения; литеральные цвета живут в apps/project-board/src/tokens.css. Локальные шрифты/иконки нужны для offline.
- При работе с Ганттом сначала читать docs/adr/PBT-003.md и docs/adr/PBT-017.md; ограничения компонентов — docs/research/PBT-014.md и PBT-015.md. Не менять календарную семантику, включительность дат и стратегию жестов ради UI или метрик.
- Новым виджетам следовать docs/widget-development.md. Проверять реальный SDK, не описывать вымышленный API.
- Исправление не должно размонтировать скрытые окна или менять соседние виды ради локального удобства. Не менять схемы данных без согласованной миграции.
