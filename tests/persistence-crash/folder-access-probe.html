PBT-140 · проверка доступа к папке

Создайте пустую папку для пробы. Здесь используется только файл pbt-140-folder-probe.txt в выбранной папке; данные дашборда не затрагиваются.

  1. Нажмите «Записать» и выберите пустую папку.
  2. Убедитесь, что показано содержимое записанного файла.
  3. Очистите данные сайта только для этого адреса через DevTools → Application → Storage → Clear site data, затем обновите страницу.
  4. Нажмите «Прочитать» и снова выберите ту же папку. Содержимое файла должно остаться прежним.
Ожидание проверки.
