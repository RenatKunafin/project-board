## Условия офлайн и ограничения инструмента

Тестовый прокси `tests/planning/network-proxy.mjs` перед обычным preview добавляет `Cache-Control: no-store` и по команде разрывает соединения с приложением. Отдельный API-запрос, обходящий браузерный SW, подтверждает недоступность origin. Файлы приложения, Service Worker и содержимое БД не подменяются. После ожидания SW и записи данных все страницы закрываются; новая страница загружается из precache.

Chromium/Chrome/Firefox дополнительно используют `context.setOffline(true)`. В WebKit 1.63 это ломает SW-навигацию даже на минимальной независимой странице: `WebKit encountered an internal error`. Для него доказана работа при недоступности origin, **полное физическое отключение сети и состояние navigator.onLine=false этим прогоном не проверены**. Собственный минимальный воспроизводитель — `tests/planning/offline-probe.mjs`; это диагностика инструмента, а не доказательство работоспособности продукта.

У Firefox тот же воспроизводитель показывает `NS_ERROR_OFFLINE` при сочетании `context.route` и offline; без routing запуск проходит. Поэтому HTTP-кэш выключается заголовком прокси, без routing. Официальная [документация Playwright](https://playwright.dev/docs/service-workers) описывает ограничения инструментов SW. Проблема WebKit 1.63 также описана в [issue #42775](https://github.com/microsoft/playwright/issues/42775), закрытом с меткой 1.64; зависимость проекта в этой задаче не обновлялась.

## Воспроизведение

Перед browser-прогонами остановить dev/MCP/старые preview; порты 4173/4185 должны быть свободны. Запуски последовательные, production-сборка обязательна. Установленный Google Chrome нужен для проекта `chrome`; отсутствие браузера не должно приводить к скрытой подмене Chromium.

```bash
npm ci
npx playwright install chromium firefox webkit
npm run lint
npm run typecheck
npm test
npm run build
npm run test:browser
npm run test:planning
openspec validate --all --strict
```

Отдельные проекты:

```bash
npm run test:planning -- --project=chromium
npm run test:planning -- --project=firefox
npm run test:planning -- --project=webkit
npm run test:planning -- --project=chrome
```

Диагностика ограничения Playwright (самостоятельный localhost:4186, не продуктовый сценарий):

```bash
node tests/planning/offline-probe.mjs
```

Сценарии: `tests/planning/planning.spec.ts`, общие UI-операции: `helpers.ts`, конфигурация: `playwright.planning.config.ts`. JSON полного прогона — `test-results/planning-results.json`; downloads/скриншоты и failure-trace — `test-results/planning/`. Общий browser-набор очищает `test-results`, поэтому planning запускается после него; необходимые артефакты следует сохранить до следующего запуска.

## Браузерная матрица и согласованная бета-проверка

Playwright WebKit не является проверкой установленного Safari, а Playwright Firefox не подтверждает обычный Firefox со всеми отличиями поставки. На машине есть Safari 26.6.2, но реальная проверка Safari не выполнена; Edge и обычный Firefox не установлены. Предыдущие версии четырёх браузеров не проверены. Две последние мажорные версии по ADR PBT-002 нельзя считать покрытыми таблицей выше.

Решение владельца 2026-10-23: «Ограничимся полученным результатом, другие браузеры проверим в ходе бета-тестирования в ручном режиме». Полученных проверок достаточно для PBT-057; последний пункт DoD закрыт по этому уточнению. Оставшаяся матрица переносится в ручное бета-тестирование и не объявляется выполненной. Целевые браузеры ADR PBT-002 сохраняются. Публикация PBT-059 отложена по решению владельца; следующий технический этап после приёмки этой проверки — PBT-058.
